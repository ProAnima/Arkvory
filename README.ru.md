## Что это

Arkvory — репозиторий для файлов, которые производят ваши сборки, на вашем собственном сервере. Он хранит сборки, пакеты и большие ассеты и доставляет их тем, кому они нужны: агентам развёртывания, конвейерам CI/CD, тестовым машинам, разработчикам и игровым командам.

Это самостоятельный продукт со своим HTTP API, клиентом командной строки и TypeScript SDK. Он также говорит на протоколах, которые уже знают ваши инструменты: реестр OCI для Docker и Podman, сервер Git LFS и npm-реестр для Unity Package Manager.

## Возможности

- **Файлы любого размера.** Загрузка идёт частями и продолжается после обрыва связи или перезапуска; скачивание продолжается по HTTP Range. Один объект — до ~10 ТиБ. Каждый файл проверяется по SHA-256.
- **Всё — в репозиториях.** Пакеты UPack с версиями, файлы по пути с историей, образы контейнеров, объекты Git LFS, пакеты npm и Unity — каждый хранится как неизменяемый артефакт.
- **Понятный доступ.** Учётные записи, группы, персональные токены доступа и сервисные учётные записи, ключи которых получают только нужные действия в нужных репозиториях. Входы и изменения доступа журналируются.
- **Стадии и продвижение.** Отметьте сборку `qa`, `release` или `prod`, опубликуйте её в другом репозитории без повторной загрузки, а агент развёртывания запросит «новейшую сборку `release` в диапазоне `^1.4`».
- **Метаданные.** Метки, текстовые метаданные, коллекции и вложения: манифесты, SBOM, подписи, отчёты.
- **Хранение.** Последние N сборок каждого пакета, квоты и предупреждения, освобождение места в фоне без остановки сервера.
- **Резервные копии.** Агент по расписанию копирует базу и всё содержимое на другой диск или сетевую папку, проверяет копии и восстанавливает в пустую цель.
- **Высокая доступность на одной площадке.** Два или три Linux-сервера держат одну синхронную копию всех данных (DRBD, Pacemaker, обязательный fencing): если активный сервер отказал, работу принимает другой, а запись подтверждается, только когда она лежит в двух полных копиях.
- **Зеркала и шлюзы чтения.** Вторая установка держит копию репозиториев только для чтения и раздаёт её, если основная площадка потеряна; дополнительные процессы скачивания делят общий бюджет полосы.
- **Работает сам.** Службы Windows, пакеты Linux или Docker Compose. Службы перезапускаются после падения или зависания; подписанные стабильные обновления ставятся вручную или в час обслуживания, после свежей проверенной резервной копии, с откатом.
- **Консоль на одиннадцати языках.** Английский, русский, испанский, французский, немецкий, португальский, китайский, японский, корейский, хинди и арабский; светлая и тёмная тема. Документация — на тех же языках.

## Установка

| Платформа                                  | Пакет                                                                                      | Руководство                                                      |
| ------------------------------------------ | ------------------------------------------------------------------------------------------ | ---------------------------------------------------------------- |
| Windows 10/11, Windows Server 2019+ (x64)  | `Arkvory-Setup-x64.exe` — мастер, Node.js и PostgreSQL в комплекте; работает без интернета | [Windows](https://proanima.github.io/Arkvory/ru/install/windows) |
| Debian, Ubuntu, Fedora, совместимые с RHEL | `Arkvory-amd64.deb`, `Arkvory-x86_64.rpm` со службами systemd                              | [Linux](https://proanima.github.io/Arkvory/ru/install/linux)     |

Скачивайте только с [GitHub Releases](https://github.com/ProAnima/Arkvory/releases) и сверяйте контрольные суммы SHA-256. Сервер слушает `127.0.0.1:8080`, пока вы не настроите [HTTPS](https://proanima.github.io/Arkvory/ru/install/https). Консоль — по адресу `/console/`.

## Первые шаги

1. Установите сервер и откройте `http://127.0.0.1:8080/console/`.
2. Создайте учётную запись владельца (мастер Windows делает это сам).
3. Создайте персональный токен доступа или ключ сервисной учётной записи.
4. Загрузите файл и скачайте его:

```bash
curl -T ./Setup.exe -H "Authorization: Bearer $ARKVORY_KEY" \
  http://127.0.0.1:8080/api/v1/repositories/releases/raw/builds/game/1.0/Setup.exe
curl -fL -H "Authorization: Bearer $ARKVORY_KEY" -o Setup.exe \
  http://127.0.0.1:8080/api/v1/repositories/releases/raw/builds/game/1.0/Setup.exe
```

Подробно: [Быстрый старт](https://proanima.github.io/Arkvory/ru/guide/quick-start).

## Ограничения

Отдельная установка — один сервер с PostgreSQL и локальным каталогом содержимого: если он остановился, клиенты ждут его возвращения. Кластеру высокой доступности нужны Linux-серверы на одной площадке с DRBD 9, Pacemaker и устройством fencing для каждого сервера; Windows и Docker Compose остаются отдельными серверами. От потери площадки не защищает ни то, ни другое: используйте резервные копии и при необходимости зеркало на второй площадке. Содержимое и хранилище копий — локальные каталоги; S3 не реализован. Новое хранилище копий по умолчанию зашифровано, recovery kit хранится вне сервера.

## Для разработчиков

Нужны Node.js 24 LTS, npm 11 и PostgreSQL 18 (Docker — по желанию).

```bash
git clone https://github.com/ProAnima/Arkvory.git
cd Arkvory
npm ci
npm run build
npm run gate -- quick
```

Запуск из исходников — для разработки; серверы ставятся из пакетов релиза.
