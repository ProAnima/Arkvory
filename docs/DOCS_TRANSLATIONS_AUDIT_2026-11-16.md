# Аудит документации и переводов — 2026-11-16

Срез рабочей ветки поверх `8d653e39e4989c6dec273d06b02ed675c49991d2`.
Это проверка документации и её исполняемых примеров, а не новая приёмка
опубликованного выпуска или конкретной производственной площадки.

## Объём

Начальный инвентарь — 701 Markdown-файл: 506 пользовательских страниц
wiki (46 страниц на каждом из 11 языков) и 195 остальных документов.
Проверены локальные пути и якоря; исторические ADR, планы и датированные
результаты сохранены как исторические записи.

Консоль содержит 1174 исходных ключа; у каждого языка проверены полнота,
актуальность исходного английского текста и плейсхолдеры. У справочника API
146 операций, 13 кодов ошибок и 58 причин; переводы операций, описаний полей,
ошибок, текстов сайта и глоссариев проверяются относительно текущего контракта.

Все 68 ранее непереведённых страниц японского и арабского разделов переведены
полностью. Все 11 языков включены в `COMPLETE`: английская заглушка теперь
считается ошибкой для любого существующего языка. Проверка структуры всех
460 переводов не находит пропущенных заголовков, UI-меток, блоков кода или
технических идентификаторов. Структурная проверка не заменяет смысловую вычитку.

Для ранее полных переводов дополнительно сверены числовые ограничения,
блоки содержания и примеры кода. Различия, оставленные намеренно, —
локализованные комментарии, человекочитаемые значения и дополнительные
пояснения интерфейса. Независимая смысловая сверка охватила все 68 новых
страниц и 72 критические страницы прежних переводов (9 страниц на каждом
из остальных 8 языков), относительно английского источника и реализации.
Дополнительно вычитаны 12 ранее переведённых арабских страниц и отдельные
разделы прежних японских, испанских, французских, корейских, русских,
китайских и хинди-переводов. Найденные общие расхождения исправлены на всех
языках. Расширенная независимая вычитка оставшихся страниц прервана лимитом
сервиса субагентов: она не объявляется завершённой. Автоматическая проверка
охватывает весь корпус; полного независимого лингвистического заключения
для каждого из 460 переводов этот отчёт не даёт.

## Исправления

- Удалена ссылка на отсутствующий `IMPLEMENTATION_STATUS.md` в ADR 0071.
- Сохранён регистр camelCase-якорей операций API при рендеринге VitePress:
  прежняя нормализация ссылок переводила фрагмент в нижний регистр, хотя
  явный id операции оставался прежним. В API_MAP добавлен устойчивый якорь
  раздела резервных копий.
- Исправлено распознавание ограждений кода с отступом в проверке заголовков;
  добавлен текстовый alias для подсветки Caddyfile.
- В переводах восстановлены отсутствовавшие права `artifact.delete`,
  `storage.read`, `storage.manage`, ошибка `routes_unsupported` и глобальные
  флаги CLI ожидания, класса и временного окна.
- Во всех языках исправлены размер отдельного пула долгих сессий каталога
  (8 вместо 3), единицы таймаута, назначение лимита активных скачиваний и
  чтение настроек модулей агентом резервного копирования. Удалена
  несуществующая группа `ARKVORY_SHARED_DOWNLOADS_*`; указаны реальные
  параметры шлюзов и общего бюджета.
- В инструкции конфигурации обновлены defaults API query pool (20),
  одновременных загрузок (8) и обе формулы лимитов на одного принципала.
  Для расчёта `max_connections` учтены отдельные пулы запросов, сессий и
  блокировок API/worker, а также оба пула backup. Исправлены единицы
  `tcp_keepalives_count`: число проб, а не секунды.
- Восстановлены default hostname, расположение `fleet.key` в каталоге данных
  и предупреждение о проверке задержки реальным fence agent для исключения
  отключения обоих узлов. Исправлены переводы CA-сертификатов получателей
  webhook, учётных данных в немецком аудите, рабочего диска DRBD и
  условия HTTPS/HTTP в корейском разделе.
- Уточнены границы доверия reverse proxy: без доверенного адреса нельзя
  подменить IP клиента, request id или host; повышение публичной схемы
  до HTTPS по `X-Forwarded-Proto` — отдельное предусмотренное поведение.
- Требования администратора и `--root` ограничены соответствующими
  командами управления установкой. Отсутствие failover относится к
  standalone, а не к поддерживаемому HA-кластеру с fencing.
- Истёкший срок в примере single-copy заменён вычислением будущего UTC
  времени. SDK-пример promotion теперь выбирает ту же группу пакета,
  что соседние примеры HTTP и CLI.
- Пример возобновления raw download использует сохранённый ETag исходного
  GET, размер существующего частичного файла и временный ответ. Только
  `206` дописывается; `200` и ошибка запроса сохраняют частичный файл.
  Исправлено несогласованное значение SHA-256 в примере события.
- В четырёх протокольных инструкциях исправлены старые defaults загрузок:
  8 одновременно на сервер, 4 на принципала; справочник учитывает формулу
  `min(4, ARKVORY_MAX_UPLOADS)` и аналогичную формулу скачиваний.
- Уточнены публичные login/register/options/live/status и закрытые
  ready/metrics; регистрация при выключенной настройке возвращает
  `403 registration_disabled`. Долг неверных паролей аккаунта хранится в
  PostgreSQL и переживает перезапуск; неверный текущий пароль вне backoff
  даёт `401 current_password_invalid`, а во время backoff —
  `429 password_attempts`.
- Исправлены exit code `tree verify` при одних лишь `extra`, максимальный
  размер Git LFS и ошибочный совет обходить его через CLI. Создание owner
  установщиком относится только к графическому EXE; Windows PowerShell,
  Linux и Docker используют recovery key. Восстановлены условие включения
  ежедневных резервных копий администратором и способ выдачи service key.
- URL источника в цитатах лицензии и FAQ оформлены явными ссылками:
  автоматическое распознавание захватывало русские, японские и китайские
  кавычки и текст в URL. Условия лицензии не менялись.

Изменения английских процедур внесены во все 10 переводов в той же ветке.
Текущие инструкции и README отражают полное покрытие японского и арабского;
датированные свидетельства приёмки не объявлены результатами новых коммитов.

  с управляемым транспортом: `206`, смена представления (`200`) и отказ
