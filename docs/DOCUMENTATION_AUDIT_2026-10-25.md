## Область сверки

Проверены входные описания README, карта разделов wiki, заявления о доступности и ограничениях в guide/install/use/protocols/operate/reference, инструкции модулей, лицензий и backup/restore, номера схемы и актуальные статусы инженерных документов. Генерируемый справочник API не редактируется вручную: его источники — OpenAPI, operation policies и словари. Структуру переводов, ссылки и сборку сайта проверяют существующие гейты.

Исторические ADR, датированные отчёты и исходный PROJECT_PLAN не превращены в новые результаты испытаний. Для навигации добавлен [CURRENT_STATE](CURRENT_STATE.md): поставленные возможности, подтверждённые версии, источники приёмки и реальные ограничения. Это обзор, а не доказательство выполнения каждой команды на пользовательском оборудовании.

## Сохранённые реальные ограничения

- Нет S3, ARM64/macOS-поставки, запуска сторонних плагинов и модулей в штатном Compose.
- Отдельная установка модулей, включение конфигурацией и перезапуск служб; автоматические миграции модулей отсутствуют.
- Сохраняются ограничения Windows directory fsync, неполные ja/ar-переводы, ручной переход на зеркало и ручное пробное восстановление backup.
- Pro: время восстановления зависит от каталога/диска; квоты и GC не обходятся; финальная приёмка использует целевые и сохранённые результаты. Нет заявления о производительности произвольной нагрузки 4 ТБ или испытанных независимых физических доменах отказа.
- Получение отзывов лицензий worker не означает автоматическую доставку списка отозванных версий модулей; это разные документы и механизмы.

## Проверки изменения

Изменены только Markdown-документы. Проверки выполняются штатными `npm run gate -- quick docs`; форматирование затрагивает только изменённые документы. Полный обязательный CI PR остаётся условием слияния. Новые продуктовые тесты для текстовых исправлений не добавляются; результаты текущего запуска и CI фиксируются в описании PR.
