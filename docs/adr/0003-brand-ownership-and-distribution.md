# 0003. Бренд, правообладатель и распространение

Статус: accepted; модель лицензирования заменена [ADR 0061](0061-free-source-available-license.md) (2026-10-03), бренд и правообладатель действуют. Дата: 2026-09-22.

## Контекст

Владелец проекта определил самостоятельное развитие под брендом ProAnimaStudio, создал репозиторий ProAnima/Arkvory и подтвердил, что правообладатель и держатель бренда — Ian Panaev лично. Для отдельных компаний допускаются приватные форки по специальным условиям.

## Решение

Название продукта — ProAnima Arkvory. GitHub — `https://github.com/ProAnima/Arkvory`; исходный репозиторий Private. Имена внутренних пакетов — `@proanima/arkvory-*`, корневой пакет — `@proanima/arkvory`.

Ian Panaev указан в LICENSE, NOTICE, README и manifests. Проект проприетарный; общая открытая лицензия не выдаётся. Права компаний, форки, использование и распространение определяются отдельными письменными соглашениями.

## Последствия

Package manifests остаются private с `license: UNLICENSED`, чтобы не публиковать код случайно. Технический доступ GitHub не заменяет договор. Лицензии зависимостей сохраняются. Условия партнёрского договора и применимое право уточняются отдельно; список лицензиатов в этом ADR не создаётся.

Внешние приложения интегрируются через публичный API; их доступность и цикл выпуска не определяют работу самостоятельного продукта.
