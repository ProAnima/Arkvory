# ADR 0087 — Восстановление предложения передачи

Статус: принято. Дата: 2026-10-21.

## Причина

Временный отказ политики модуля снимает предложение передачи. После восстановления
политики прежний контракт требовал перезапуска процесса, хотя маршруты оставались
зарегистрированными и могли обслуживать запросы.

## Решение

В extension-api 0.11.0 добавлен `ModuleRoutes.restoreTransfer(name)`.
Он идемпотентно снимает отметку withdrawal только в регистраторе вызывающего модуля.
Определение протокола, версии и префикс остаются проверенными при `seal`.
Неизвестное имя ничего не меняет; некорректное имя отвергается. Снятые имена остаются
зарезервированными. Новые объявления после `create` по-прежнему запрещены.

Восстановление предложения не запускает модуль и не добавляет его в набор работающих
модулей. Только сам модуль знает свою политику: перед восстановлением он обязан её
проверить, а обработчики — проверять её на каждом запросе. Модуль обязан прекратить
восстановление при drain/stop. Публичный HTTP-контракт capabilities не меняется.

## Проверка

Регрессионный тест регистратора проверяет повторные снятие/восстановление,
неизменность определения, изоляцию владельцев, резервирование имени и запрет позднего
объявления. Потребитель проверяет восстановление после таймаута в настоящем ядре.
