# ADR 0040: Единая идентичность Arkvory

Статус: принято; уточнено по подтверждению владельца, что действующих установок нет. Правообладатель и держатель бренда: Ian Panaev; ProAnimaStudio — студия.

До первого развёртывания все пространства имён унифицированы: `ARKVORY_*` для окружения, `arkvory_*` для SQL и managed credentials, `arkvory` для CLI/browser storage, служб, пакетов и релизов. Схема создаётся сразу с итоговыми именами. Числовые advisory locks и алгоритмы блокировок не зависят от бренда и не меняются.

Слой обратной совместимости названия удалён: отсутствуют aliases настроек, поиск альтернативных профилей/чекпойнтов, fallback темы/языка и блокировки установщика, предназначенные для перехода между брендами. Общий нормализатор окружения больше не нужен; worker снова зависит только от application/domain/infrastructure. Конфигурация читается в composition roots. Deploy принимает исключительно имена `ARKVORY_*` и сохраняет проверку типов и запрет управляющих символов.

Это сознательное изменение дорелизной схемы, а не сценарий обновления используемой установки. Для проверки создаётся чистая тестовая БД. Последующие изменения опубликованной схемы снова подчиняются обычной политике миграций expand/contract.

Внешние маршруты `/api/v1`, `/console`, Universal Feed и Assets сохраняются. Поддержка ProGet — отдельный контракт; удаление совместимости бренда его не затрагивает. Выдача и распознавание сервисных ключей используют один префикс `arkvory_`; проверки ACL, активации, отзыва, ротации и запрета fallback авторизации сохраняются.

Бренд задаётся `branding/identity.json`; SVG, PNG, ICO, UI, ярлыки и установщики используют общую геометрию и палитру. [Карта идентификаторов](../PRODUCT_IDENTITY.md). Проверки включают чистое создание PostgreSQL-схемы, сервисные ключи, передачи/докачку, браузерное хранилище и сборку установки через гейты.
