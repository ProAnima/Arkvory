# 0061. Бесплатная лицензия с открытым для чтения кодом

Статус: accepted. Owner: Ian Panaev. Дата: 2026-10-03. Заменяет модель лицензирования [ADR 0003](0003-brand-ownership-and-distribution.md) (проприетарный код, права только по договору); бренд и правообладатель из ADR 0003 не меняются.

## Контекст

Arkvory распространялся как проприетарный продукт: пользоваться им можно было только по отдельному договору с правообладателем, репозиторий был приватным. Правообладатель решил (2026-10-03): продукт бесплатный и не продаётся, код открыт для чтения, форки ограничены, при использовании указывается источник. Ian Panaev — единственный автор (идентичности git `Ian Panaev` и `Feargin` — один человек), поэтому вправе сменить условия сам.

Открытые лицензии (OSI: Apache, MIT, GPL и др.) по определению разрешают распространять изменённые версии, то есть форки, и цели не соответствуют. Из готовых source-available лицензий PolyForm Internal Use ближе всего, но не покрывает использование частными лицами и не требует указывать источник.

## Решение

Собственная **ProAnima Arkvory License 1.0** ([LICENSE.md](../../LICENSE.md), [LICENSE.ru.md](../../LICENSE.ru.md); при расхождении действует русский текст):

| Решение правообладателя                | Условие лицензии                                                                                                                                                                        |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Бесплатно для всех, включая компании   | Использование любого числа копий для любых целей, в том числе в работе коммерческой организации (§1)                                                                                    |
| Код открыт для чтения                  | Право читать и изучать исходный код (§1); репозиторий может быть публичным                                                                                                              |
| Можно менять для себя                  | Изменения и изменённые версии — только внутри своей организации (§1)                                                                                                                    |
| Без форков                             | Запрещено распространять программу и изменённые версии вне организации и публиковать их, включая форки, сборки, образы и патчи с кодом (§2); форк средствами хостинга прав не даёт      |
| Копии только из официальных источников | GitHub ProAnima/Arkvory, сервис обновлений ProAnimaStudio, реестры образов из документации (§2)                                                                                         |
| Не продаётся                           | Нельзя продавать, сдавать, брать плату и предоставлять программу третьим лицам как сервис; хранить и выдавать свои артефакты своим клиентам можно (§2)                                  |
| Указание источника                     | Не удалять уведомления, LICENSE, NOTICE и названия в интерфейсе (§2); при публичном описании систем на Arkvory указывать «ProAnima Arkvory, ProAnimaStudio (Ян Панаев)» со ссылкой (§3) |

Также: вклад (сообщения, предложения, pull request) лицензиар может использовать свободно (§5); прав на бренды нет (§6); описание передаваемых данных (§7); без гарантий и с ограничением ответственности (§8–9); прекращение прав при нарушении с 30 днями на исправление первого нарушения (§10); другие права — отдельным договором (§11).

Установщики Windows показывают ту же лицензию на языке мастера установки (`deploy/legal/EULA.*.txt` — дословная копия, проверяется тестом). Лицензия на двух языках и NOTICE.md входят в архив релиза, нативные пакеты и пакеты CLI. Поле `license` в манифестах — `SEE LICENSE IN LICENSE.md`; `private: true` остаётся: пакеты в npm не публикуются.

## Последствия

- Это не open source: продукт нельзя называть «открытым» или «open source»; формулировка — «бесплатный, исходный код открыт для чтения».
- Публичный репозиторий: GitHub по своим условиям позволяет форк внутри GitHub; права за пределами лицензии такой форк не даёт. Перед открытием репозитория проверяется вся история на секреты.
- Существующие договоры с партнёрами (если есть) продолжают действовать и имеют приоритет в своих пределах.
- Текст составлен без юриста; перед публичным выпуском рекомендована проверка юристом юрисдикции правообладателя.
