# ADR 0040: Arkvory и совместимость сохранённых идентификаторов

Статус: принято. Правообладатель и держатель бренда: Ian Panaev; ProAnimaStudio — обозначение студии.

Пользователь утвердил Arkvory вместо Depot. Новые пакеты, службы, релизы, CLI, интерфейс, Docker, документация и репозиторий используют новое имя. Публичные маршруты `/api/v1`, `/console`, Universal Feed и Assets не меняются из-за брендинга. ZIP/UPack, контрольные суммы и ключи доступа остаются прежними.

Имена SQL-объектов `depot_*`, advisory lock IDs, префиксы выданных ключей, OPFS namespace и Web Locks — сохранённые технические контракты. Их переименование не добавляет ценности пользователю и может создать вторую пустую схему, снять fencing или потерять доступ к временным байтам. Они сохраняются; это явное исключение из ренейминга, не незавершённый бренд в UI.

Новые настройки имеют префикс `ARKVORY_`. Чистая функция `normalizeRuntimeSettings` в contracts описывает совместимость внешнего формата runtime configuration: `DEPOT_` принимается как устаревшее имя, значения не заменяются, конфликт двух имён отклоняется без вывода секретов. Composition roots API/worker/CLI и deploy применяют этот контракт. Worker получает зависимость contracts для чтения этого формата; domain/application не читают окружение.

CLI переиспользует старые профили и checkpoints на месте, без копирования токенов и частичных файлов. Одновременное наличие старого и нового пути требует ручного разрешения конфликта. Запуск двух поколений CLI для одного незавершённого файла одновременно не поддерживается. Web читает старые theme/language как fallback, сохраняет только новые настройки.

Смена системных служб, Compose project/volumes и установочных директорий — отдельный эксплуатационный переход. Установщик не должен создавать новое пустое хранилище поверх старого. Стандартный legacy root обнаруживается до установки, legacy runtime.json отклоняется managed updater до управления службами. Полностью автоматическая конвертация существующей установки не объявляется реализованной. [Порядок перехода](../RENAMING.md).

Бренд задаётся `branding/identity.json`. Из него генерируются SVG и многомасштабные ICO/PNG; Windows wizard использует ту же геометрию и палитру. Native EXE, uninstall, ярлыки, Linux desktop entries, консоль и remote wizard получают свой вариант знака. Отдельные UI/API/installer тесты проверяют связывание ресурсов, форматы и отсутствие старого имени в видимом интерфейсе.
