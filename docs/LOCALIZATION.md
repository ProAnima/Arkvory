# Локализация: языки консоли и документации

| Переключатель в шапке | `apps/web/src/language-menu.ts`: кнопка с флагом и двумя буквами, список-popover со всеми языками (флаг, своё название, галочка); стрелки, Home, End, буква, Enter, Escape. Флаги — `apps/web/flags/<страна>.svg` (flag-icons, MIT; лицензия там же и в `THIRD-PARTY.txt`), сервер отдаёт их через `GET /console/flags/:file` (два символа и `.svg`). Флаг — страна, не язык: английский показан флагом Великобритании, португальский — Бразилии, арабский — Саудовской Аравии (`flag` в `languages.ts`) |

Состояние: 2026-10-05. Языки: английский (исходный), русский, испанский, французский, немецкий, португальский (Бразилия), китайский (упрощённый), японский, корейский, хинди, арабский — справа налево. Решение: [ADR 0068](adr/0068-documentation-site-and-languages.md).

## 1. Где живут тексты {#where}

| Что                                                          | Где                                                                                                                                                         |
| ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Список языков: код, своё название, направление, локаль чисел | `apps/web/src/languages.ts` (`LANGUAGES`); сайт читает его же (`wiki/.vitepress/languages.ts`)                                                              |
| Тексты консоли, английский и русский                         | `apps/web/src/*-messages.ts`, сборка в `messages-en.ts` / `messages-ru.ts`; тип ключей — `MessageKey`                                                       |
| Тексты консоли на других языках                              | `apps/web/locales/<code>.json`: `{ "key": { "en": "<английский оригинал>", "text": "<перевод>" } }`                                                         |
| Что получает браузер                                         | `apps/web/public/locales/<code>.json` — только тексты; пишет `scripts/build.mjs`                                                                            |
| Выбор и применение языка                                     | `apps/web/src/i18n.ts` (`setLanguage`, `initializeLanguage`, `documentationUrl`), `preferences.ts`, `appearance-init.ts` (`lang`/`dir` до первой отрисовки) |
| Отдача словарей сервером                                     | `GET /console/locales/:file` (`apps/api/src/console.ts`): только `[a-z]{2}.json`                                                                            |
| Глоссарий терминов                                           | `wiki/i18n/terms/<code>.json`; английский — с пояснениями                                                                                                   |
| Страницы документации                                        | `wiki/<section>/<page>.md` (английский), `wiki/<code>/<section>/<page>.md` (переводы)                                                                       |
| Что говорит сам сайт                                         | `wiki/.vitepress/text/<code>.json`: разделы, кнопки темы, поиск, слова справочника API                                                                      |
| Тексты справочника API                                       | `wiki/i18n/api/<code>.json`: `operations`, `errors`, `fields`                                                                                               |

Язык консоли — сохранённый выбор (`localStorage`, ключ `language`), иначе первый язык браузера (`navigator.languages`), который есть у консоли, по базовому коду (`pt-BR` → `pt`), иначе английский. Английский и русский в бандле; другой словарь загружается при выборе и кэшируется на время страницы. Переключение перерисовывает все узлы с `data-i18n*` и не сбрасывает формы и передачи. Если словарь не загрузился, переключатель возвращается к текущему языку.

Переключатель показывает каждый язык его собственным названием (_Deutsch_, _日本語_) и в его направлении письма, на каком бы языке ни была страница.

**Справа налево.** Арабский ставит `<html dir="rtl">`: CSS консоли использует логические свойства (`inline-start/end`), поэтому раскладка зеркалится. Код, ключи, хэши и адреса остаются слева направо. Числа — латинскими цифрами (`intl: "ar-u-nu-latn"`), как размеры и порты рядом с ними.

**Разрядка.** Мелкие подписи капителью разрежены в латинице и кириллице; в арабском, деванагари и CJK разрядки нет (`:lang()` в CSS консоли и сайта).

## 2. Как писать текст {#writing}

- Один ключ — одна вещь, которую читает человек; имя по экрану (`backup*`, `storage*`, `permission.*`, `error*`).
- Значения — плейсхолдеры `{name}`, никогда не склейка строк. Множественного числа в консоли нет: формулируйте нейтрально («Файлов: {count}», «{count} / 32»).
- Не переводятся: Arkvory, ProAnimaStudio, UPack, Git LFS, OCI, Docker, npm, Unity, PostgreSQL, SHA-256, HTTP(S), API, CLI, SDK; команды, флаги, переменные `ARKVORY_*`, пути, заголовки HTTP, идентификаторы прав (`artifact.read`), значения стадий (`release`), примеры (`*Example`).
- Кнопки, вкладки, заголовки колонок — коротко: ширины фиксированы, цель касания 44 px.
- Термины — по глоссарию языка (`wiki/i18n/terms/<code>.json`), одинаково в консоли и в документации.
- Новый текст добавляется в английский и русский словари, затем в каждый `apps/web/locales/*.json` (`en` — текущий английский, `text` — перевод). Изменили английский — обновите `en` и `text` во всех файлах: тест покажет устаревшие.

## 4. Как добавить язык {#adding}

1. Строка в `LANGUAGES` (`apps/web/src/languages.ts`): код BCP 47, своё название, `dir: 'rtl'` для письма справа налево, `intl` — если числа нужно писать не по умолчанию.
2. `apps/web/locales/<code>.json`: скопируйте файл другого языка, замените все `text`; `en` оставьте.
3. `wiki/i18n/terms/<code>.json` — глоссарий; `wiki/.vitepress/text/<code>.json` — тексты сайта; `wiki/i18n/api/<code>.json` — тексты справочника.
4. `wiki/<code>/` — страницы английской документации с теми же id заголовков, метками и блоками кода; недостающие показываются по-английски как заглушки (`npm run wiki -- stubs`, см. [WIKI](WIKI.md#stubs)). В `COMPLETE` язык попадает, когда переведено всё.
5. `npm run gate -- quick`, затем гейты `browser` и `docs`: тесты назовут каждый пропущенный текст и страницу.

## 5. Что не переводится намеренно {#not-translated}

- **Данные пользователя**: имена артефактов, метки, метаданные, комментарии.
- **Раздел документации для разработчиков** — копия `docs/` на русском.
- **Журналы сервера и ответы API**: `message` ошибки — английский текст для журнала; клиенты решают по `code` и `reason`, консоль показывает свой текст по коду.
- **Установщик Windows, мастер удалённой установки, `arkvoryctl`** — пока английский и русский.
- **Отзыв в хаб** уходит с языком `ru` или `en`: другой язык консоли отправляется как `en` (контракт хаба).
- **Лицензия** — `LICENSE.md` и `LICENSE.ru.md`; при расхождении действует русский текст.
