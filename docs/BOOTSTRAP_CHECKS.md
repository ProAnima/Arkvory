# Проверка каркаса

> Исторический отчёт проверки исходного каркаса. Текущие проверки ядра: [CORE_VALIDATION](CORE_VALIDATION.md).

Дата: 2026-09-22. Среда проверки: Windows, Node.js 24.13.0, npm 11.6.2. Для эксплуатации устанавливается актуальный безопасный patch выбранной Node.js 24 LTS-линии.

## Выполнено

- Установлены зафиксированные dev-зависимости, создан package-lock.json.
- Проверены TypeScript-конфигурации всех 10 workspaces, type-aware ESLint, форматирование и граф зависимостей.
- Проверены JSON-файлы, локальные ссылки Markdown и парность code fences.
- Контрольный разрешённый импорт `api → application` проходит.
- Контрольные запрещённые импорты `domain → infrastructure`, `sdk → api` и Node.js API из domain отклоняются.
- Попытка обойти workspace-имя относительным импортом другого пакета отклоняется.
- Присваивание null строке отклоняется TypeScript strict; explicit any отклоняется ESLint.

Негативные проверки выполнялись временными файлами, удалёнными после проверки. Они проверяют конфигурацию ограничений, а не функциональность хранилища.

## Повторение основных проверок

```sh
npm ci
npm run check
```

## Не реализовано и не проверялось

API сервиса, UI, PostgreSQL migrations, публикация UPack/assets, передача 5 ГБ, очереди, HA и восстановление данных. Эти результаты нельзя выводить из успешных проверок каркаса. Они входят в следующие этапы roadmap.
