# 站点

**站点**是一个 Arkvory 安装：主安装、位于其他地点的镜像、从另一安装导入版本的安装。在 [[ui:fleet]] 中，一个安装（**控制站点**）显示它管理的每个站点：是否应答、版本、HA 副本和只读网关、镜像及其落后多少，以及下载队列。只有全局管理员能看到此页面。

## 工作方式 {#how-it-works}

- 控制站点保存站点列表。它每 30 秒通过 HTTPS 读取每个站点并保留最后的应答，因此停止应答的站点仍会显示最后已知的状态。
- 配对时，站点给控制站点一个专属密钥，即**集群密钥**。它只能访问控制站点所需的内容：站点状态及其目录中的描述。它不能下载文件字节、修改任何内容，也不能读取账户和密钥。
- 控制站点用其数据目录中的密钥（`fleet.key`）封存集群密钥。仅凭数据库及其备份无法得到它们。恢复后请重新配对站点。
- 每个站点都显示哪些控制站点在管理它，并可随时撤销。

## 配对站点 {#pair}

1. 在站点上：打开 [[ui:fleet]]，在 [[ui:fleetThisSite]] 下选择 [[ui:fleetMakeCode]]。站点显示一个十分钟内有效的代码；使用内置 HTTPS 时，还会显示其证书指纹。
2. 在控制站点上：打开 [[ui:fleet]]，在 [[ui:fleetAdd]] 下输入站点地址并选择 [[ui:fleetCheck]]。控制站点连接后显示收到的证书指纹。
3. 比较两个指纹。它们必须相同。如果不同，说明地址错误或两个安装之间有其他东西：不要配对。
4. 输入代码并选择 [[ui:fleetPair]]。站点出现在列表中并显示其状态。

代码只能使用一次。已使用或已过期的代码会被拒绝：请生成新代码。

地址是站点 API 的 HTTPS 地址，例如 `https://branch.example:8443`。明文 HTTP 只在同一台计算机上（`127.0.0.1`）被接受。如果 TLS 在站点前面的代理处终止，站点无法显示代理的证书：请与浏览器为站点地址显示的 SHA-256 指纹比较。

此后控制站点只信任这一个证书。站点换了新证书时会显示 [[ui:fleetStateCertificate]]：请移除站点并重新配对。

## 状态 {#states}

| 状态                         | 含义                           | 处理                                      |
| ---------------------------- | ------------------------------ | ----------------------------------------- |
| [[ui:fleetStateOk]]          | 站点应答了最近一次读取         | 无需处理                                  |
| [[ui:fleetStatePending]]     | 站点尚未被读取                 | 等待下一次读取或选择 [[ui:fleetReadSite]] |
| [[ui:fleetStateUnreachable]] | 没有应答：站点已停止或网络中断 | 检查站点和网络。最后已知的状态仍然可见    |
| [[ui:fleetStateCertificate]] | 站点出示的证书与已确认的不同   | 如果证书已续签，请移除站点并重新配对      |
| [[ui:fleetStateRevoked]]     | 站点管理员撤销了此控制站点     | 用新代码重新配对                          |
| [[ui:fleetStateInvalid]]     | 站点的应答本版本无法理解       | 将两个安装升级到同一版本                  |
| [[ui:fleetStateRefused]]     | 站点拒绝了请求                 | 用新代码重新配对                          |

## 列表显示的内容 {#list}

- **[[ui:fleetVersion]]**：站点的版本及其角色，写入或只读网关。
- **[[ui:fleetCopies]]**：在 HA 集群中，完整副本数以及写入所需的副本数；持有槽位的只读网关。
- **[[ui:fleetMirrors]]**：站点的镜像和导入；最落后的一个比源落后多少变更，或有多少已停止。
- **[[ui:fleetQueue]]**：正在进行的下载和在队列中等待的下载。
- **[[ui:fleetSeen]]**：站点最后一次应答的时间。

[[ui:fleetReadAll]] 立即读取所有站点，而不等待下一轮。[[ui:fleetRemoveSite]] 在此处忘记站点；也请在该站点上撤销控制站点，因为在此之前其密钥在那里仍然有效。

## 站点内容 {#content}

站点行中的 [[ui:fleetContent]] 在列表下方打开其仓库、制品和文件。选择一个仓库；[[ui:fleetFind]] 按名称或标签搜索制品，并列出路径以所输入内容开头的文件。[[ui:fleetMore]] 读取下一页。

控制站点用其集群密钥在站点上读取这些内容，并按站点给出的原样显示应答。只传输描述：名称、大小、标签、阶段、路径和修订。要下载文件，请使用站点本身。

## 谁在管理本站点 {#managed-by}

在 [[ui:fleetThisSite]] 下，每个站点列出管理它的控制站点：名称、配对人、配对时间和最后请求。[[ui:fleetRevoke]] 立即拒绝该控制站点的密钥。

## 设置 {#settings}

| 变量                     | 默认值                   | 含义                                           |
| ------------------------ | ------------------------ | ---------------------------------------------- |
| `ARKVORY_SITE_NAME`      | 主机名                   | 本安装在其他站点上的名称                       |
| `ARKVORY_FLEET_KEY_FILE` | 数据目录中的 `fleet.key` | 封存受管站点密钥的密钥；写入进程首次启动时创建 |

## 限制 {#limits}

- 此页面显示站点状态。镜像、更新、下载队列和 HA 在各站点上配置，使用其控制台或 `arkvory configure`；从控制站点修改它们是下一步。
- 一个控制站点最多管理 256 个站点，同时最多读取八个。
- 控制站点持有其管理的每个站点的密钥：请像保护站点本身一样保护它的全局管理员和数据目录。
