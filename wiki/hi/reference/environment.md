# एनवायरनमेंट वेरिएबल

Arkvory की कॉन्फ़िगरेशन ऐसे एनवायरनमेंट वेरिएबल से होती है जिनके नाम `ARKVORY_` से शुरू होते हैं। यह पेज वे सभी वेरिएबल सूचीबद्ध करता है जिन्हें सर्वर प्रोसेस, कमांड-लाइन क्लाइंट और इंस्टॉलर स्क्रिप्ट पढ़ती हैं।

## मान कहाँ से आते हैं {#where-the-values-come-from}

इंस्टॉलर सर्वर की सेटिंग्स इंस्टॉलेशन रूट की एक फ़ाइल, `config/runtime.json`, में लिखते हैं। हर सेवा का लॉन्चर इस फ़ाइल को पढ़ता है और उसके मान API, वर्कर और बैकअप एजेंट को देता है। JSON की हर कुंजी `ARKVORY_` से शुरू होनी चाहिए और हर मान स्ट्रिंग होना चाहिए।

```json
{
  "ARKVORY_HOST": "127.0.0.1",
  "ARKVORY_PORT": "8080",
  "ARKVORY_CAPACITY_BYTES": "10995116277760",
  "ARKVORY_DATABASE_URL": "postgresql://arkvory:PASSWORD@127.0.0.1:54329/arkvory",
  "ARKVORY_DATA_DIR": "/opt/proanima-arkvory/data",
  "ARKVORY_KEYS_FILE": "/opt/proanima-arkvory/config/keys.json",
  "ARKVORY_MAX_DOWNLOADS": "32"
}
```

फ़ाइल में डेटाबेस का पासवर्ड है। उसके एक्सेस अधिकार वैसे ही रखें जैसे इंस्टॉलर ने सेट किए हैं।

सेटिंग बदलने के लिए `config/runtime.json` संपादित करें और सेवाएँ रीस्टार्ट करें। जहाँ `arkvory configure` कमांड सेटिंग को कवर करता है (HTTPS, बैकअप स्टोरेज, मिरर, अपडेट), वहाँ उसे प्राथमिकता दें। वह बदलाव जाँचता है और सेवाएँ शुरू न होने पर पुरानी फ़ाइल बहाल कर देता है। [कॉन्फ़िगरेशन](../install/configuration) देखें।

```bash
sudo systemctl restart arkvory-api arkvory-worker arkvory-backup
```

```powershell
Restart-Service Arkvoryapi, Arkvoryworker, Arkvorybackup
```

अनुमत सीमा से बाहर का मान प्रोसेस को शुरू होते ही रोक देता है, और संदेश में वेरिएबल का नाम होता है। इस स्थिति में Arkvory डिफ़ॉल्ट मान पर नहीं लौटता।

"कौन पढ़ता है" कॉलम इन नामों का इस्तेमाल करता है: **API** HTTP सर्वर है (रीड गेटवे भी), **वर्कर** पृष्ठभूमि का वर्कर है, **एजेंट** बैकअप एजेंट है, **CLI** `arkvoryctl` है।

## मूल सेटिंग्स {#core}

| वेरिएबल                      | कौन पढ़ता है                 | डिफ़ॉल्ट          | अर्थ                                                                                                                                                                       |
| ---------------------------- | ---------------------------- | ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ARKVORY_DATABASE_URL`       | API, वर्कर, एजेंट, माइग्रेशन | आवश्यक            | PostgreSQL कनेक्शन URL (`postgres://` या `postgresql://`)। हर इंस्टॉलेशन के लिए अलग डेटाबेस इस्तेमाल करें।                                                                 |
| `ARKVORY_DATA_DIR`           | API, वर्कर, एजेंट            | आवश्यक            | स्थानीय स्टोरेज डायरेक्टरी: स्टेजिंग, सामग्री और `storage-id` फ़ाइल। नेटवर्क शेयर इस्तेमाल न करें।                                                                         |
| `ARKVORY_HOST`               | API                          | `127.0.0.1`       | जिस पते पर कनेक्शन स्वीकार करने हैं। इंस्टॉलर `127.0.0.1` लिखते हैं; Docker Compose में कंटेनर के भीतर यह `0.0.0.0` है, और पोर्ट केवल होस्ट के लूपबैक पर प्रकाशित होता है। |
| `ARKVORY_PORT`               | API                          | `8080`            | TCP पोर्ट, 1–65535।                                                                                                                                                        |
| `ARKVORY_WEB_DIR`            | API                          | `apps/web/public` | वेब कंसोल की फ़ाइलों वाली डायरेक्टरी। लॉन्चर हर शुरुआत पर इसे वर्तमान रिलीज़ पर सेट करता है।                                                                               |
| `ARKVORY_DATABASE_POOL_SIZE` | API                          | `10`              | API के कनेक्शन पूल का आकार, 4–200। तीन तक कनेक्शन हमेशा इस्तेमाल में रहते हैं।                                                                                             |

## स्टोरेज और सीमाएँ {#storage-and-limits}

| वेरिएबल                         | कौन पढ़ता है      | डिफ़ॉल्ट     | अर्थ                                                                                                                                                                                       |
| ------------------------------- | ----------------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `ARKVORY_CAPACITY_BYTES`        | API, वर्कर        | 10 TiB       | सभी आरक्षित सामग्री के लिए बाइट में ऊपरी सीमा: प्रकाशित सामग्री, अधूरे अपलोड और क्लीनअप की प्रतीक्षा करती सामग्री। यह डिस्क की जाँच नहीं है। वर्कर इसे केवल मिरर प्रतियों के लिए पढ़ता है। |
| `ARKVORY_STORAGE_RESERVE_BYTES` | API, वर्कर, एजेंट | `1073741824` | बाइट में वह खाली जगह जिसे अपलोड कभी इस्तेमाल नहीं करते। यह डेटाबेस, लॉग और सिस्टम के लिए रखी जाती है। `0` रिज़र्व बंद कर देता है।                                                          |
| `ARKVORY_MAX_OBJECT_BYTES`      | API               | लगभग 10 TiB  | बाइट में सबसे बड़ा ऑब्जेक्ट। अनुमत सबसे ऊँचा मान 1 GiB के 10 000 भाग हैं। फ़ाइल का आकार सीमित करने के लिए कम मान सेट करें।                                                                 |

## ट्रांसफ़र और बैंडविड्थ {#transfers-and-bandwidth}

ये सीमाएँ एक API प्रोसेस की हैं। दरें बाइट प्रति सेकंड में हैं: `0` का मतलब कोई सीमा नहीं, कोई दूसरा मान 65 536 से 1 TiB के बीच होना चाहिए।

| वेरिएबल                                           | कौन पढ़ता है | डिफ़ॉल्ट  | अर्थ                                                                                                                                                                           |
| ------------------------------------------------- | ------------ | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `ARKVORY_MAX_UPLOADS`                             | API          | `2`       | एक साथ चलने वाले अपलोड, 1–32।                                                                                                                                                  |
| `ARKVORY_MAX_DOWNLOADS`                           | API          | `16`      | एक साथ चलने वाले डाउनलोड, 1–256।                                                                                                                                               |
| `ARKVORY_MAX_UPLOADS_PER_PRINCIPAL`               | API          | `1`       | एक खाते या कुंजी के एक साथ चलने वाले अपलोड, कुल अपलोड सीमा तक।                                                                                                                 |
| `ARKVORY_MAX_DOWNLOADS_PER_PRINCIPAL`             | API          | `4`       | एक खाते या कुंजी के एक साथ चलने वाले डाउनलोड, कुल डाउनलोड सीमा तक।                                                                                                             |
| `ARKVORY_TRANSFER_QUEUE_LIMIT`                    | API          | `64`      | खाली स्लॉट की प्रतीक्षा कर सकने वाले ट्रांसफ़र, 1–1024।                                                                                                                        |
| `ARKVORY_TRANSFER_QUEUE_PER_PRINCIPAL`            | API          | `8`       | एक खाते या कुंजी के प्रतीक्षारत ट्रांसफ़र, कतार की सीमा तक।                                                                                                                    |
| `ARKVORY_TRANSFER_QUEUE_TIMEOUT_MS`               | API          | `20000`   | ट्रांसफ़र कतार में कितनी देर प्रतीक्षा कर सकता है, 1–120 000 ms।                                                                                                               |
| `ARKVORY_MAX_REQUESTS`                            | API          | `128`     | एक साथ चलने वाले प्रमाणित अनुरोध, 1–4096। यह अपलोड और डाउनलोड के योग से अधिक होना चाहिए। सेट न होने पर और ट्रांसफ़र सीमाएँ ऊँची होने पर डिफ़ॉल्ट अपलोड + डाउनलोड + 64 होता है। |
| `ARKVORY_UPLOAD_BYTES_PER_SECOND`                 | API          | `0`       | प्रोसेस की कुल अपलोड दर।                                                                                                                                                       |
| `ARKVORY_DOWNLOAD_BYTES_PER_SECOND`               | API          | `0`       | प्रोसेस की कुल डाउनलोड दर।                                                                                                                                                     |
| `ARKVORY_UPLOAD_BYTES_PER_SECOND_PER_PRINCIPAL`   | API          | `0`       | एक खाते या कुंजी की अपलोड दर, उसके सभी कनेक्शन मिलाकर।                                                                                                                         |
| `ARKVORY_DOWNLOAD_BYTES_PER_SECOND_PER_PRINCIPAL` | API          | `0`       | एक खाते या कुंजी की डाउनलोड दर, उसके सभी कनेक्शन मिलाकर।                                                                                                                       |
| `ARKVORY_UPLOAD_IDLE_TIMEOUT_MS`                  | API          | `30000`   | जो अपलोड अनुरोध इतनी देर तक कोई डेटा नहीं भेजता, उसे रोक दिया जाता है, 1–1 800 000 ms।                                                                                         |
| `ARKVORY_UPLOAD_DEADLINE_MS`                      | API          | `1800000` | एक अपलोड अनुरोध का सबसे लंबा समय, 1–1 800 000 ms। यह निष्क्रियता टाइमआउट से कम नहीं हो सकता।                                                                                   |

## नेटवर्क, HTTPS और ब्राउज़र {#network-https-and-browsers}

| वेरिएबल                      | कौन पढ़ता है | डिफ़ॉल्ट  | अर्थ                                                                                                                  |
| ---------------------------- | ------------ | --------- | --------------------------------------------------------------------------------------------------------------------- |
| `ARKVORY_TLS_CERT_FILE`      | API          | सेट नहीं  | बिल्ट-इन HTTPS के लिए PEM सर्टिफ़िकेट (अपनी चेन के साथ)। इसे कुंजी फ़ाइल के साथ सेट करें।                             |
| `ARKVORY_TLS_KEY_FILE`       | API          | सेट नहीं  | बिना पासवर्ड की PEM निजी कुंजी।                                                                                       |
| `ARKVORY_TLS_MIN_VERSION`    | API          | `TLSv1.2` | `TLSv1.2` या `TLSv1.3`।                                                                                               |
| `ARKVORY_TLS_RELOAD_SECONDS` | API          | `300`     | नवीनीकृत सर्टिफ़िकेट फ़ाइलें कितनी बार पढ़ी जाती हैं: 30–86 400 सेकंड, या `0` यानी उन्हें केवल शुरू होते समय पढ़ना।   |
| `ARKVORY_CORS_ORIGINS`       | API          | खाली      | 16 तक ब्राउज़र ऑरिजिन की अल्पविराम से अलग सूची, किसी दूसरे पते पर चल रहे कंसोल के लिए। केवल HTTPS, या लूपबैक पर HTTP। |
| `ARKVORY_TRUSTED_PROXIES`    | API          | खाली      | 32 तक रिवर्स प्रॉक्सी पते (IP या CIDR)। केवल यही `X-Forwarded-For` से क्लाइंट का पता सेट कर सकते हैं।                 |

बिल्ट-इन HTTPS नेटिव इंस्टॉलेशन के लिए है। Docker Compose के साथ रिवर्स प्रॉक्सी इस्तेमाल करें। [HTTPS](../install/https) देखें।

| वेरिएबल                      | कौन पढ़ता है | डिफ़ॉल्ट | अर्थ                                                                                                                                    |
| ---------------------------- | ------------ | -------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `ARKVORY_KEYS_FILE`          | API, वर्कर   | आवश्यक   | फ़ाइल कुंजियों वाली JSON फ़ाइल, जैसे पुनर्प्राप्ति कुंजी और हेल्थ चेक कुंजी। इसमें कुंजियों के SHA-256 हैश रहते हैं, कुंजियाँ कभी नहीं। |

## बैकअप {#backups}

| वेरिएबल                           | कौन पढ़ता है       | डिफ़ॉल्ट      | अर्थ                                                                                                                                                                            |
| --------------------------------- | ------------------ | ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ARKVORY_BACKUP_VAULT`            | एजेंट              | सेट नहीं      | इनिशियलाइज़ किए गए बैकअप स्टोरेज (vault) की डायरेक्टरी। इसके बिना एजेंट चलता है और बताता है कि कोई वॉल्ट कॉन्फ़िगर नहीं है। `arkvory configure --backup-vault` इसे लिखता है।    |
| `ARKVORY_BACKUP_VAULT_KEY_FILE`   | एजेंट              | सेट नहीं      | एन्क्रिप्टेड vault के लिए एजेंट की कुंजी (`AK1-…`) वाली फ़ाइल, या रिकवरी किट। कमांड इसे `--key-file` के रूप में भी लेती हैं। इसे `arkvory configure --vault-key-file` लिखता है। |
| `ARKVORY_BACKUP_BYTES_PER_SECOND` | एजेंट              | कोई सीमा नहीं | बैकअप की कॉपी दर की सीमा, कम से कम 65 536।                                                                                                                                      |
| `ARKVORY_BACKUP_POLL_SECONDS`     | एजेंट              | `15`          | एजेंट नए बैकअप जॉब कितनी बार जाँचता है, 1–3600 सेकंड।                                                                                                                           |
| `ARKVORY_BACKUP_LEASE_SECONDS`    | एजेंट              | `60`          | लीज़ का वह समय जो दूसरे एजेंट को एक साथ चलने से रोकता है, 2–3600 सेकंड।                                                                                                         |
| `ARKVORY_BACKUP_SNAPSHOT_SECONDS` | एजेंट              | `1800`        | बैकअप के डेटाबेस स्नैपशॉट वाले हिस्से की समय-सीमा, 60–86 400 सेकंड।                                                                                                             |
| `ARKVORY_BACKUP_BARRIER_SECONDS`  | एजेंट              | `30`          | बैकअप चल रहे क्लीनअप चरण की कितनी देर प्रतीक्षा करता है, 1–600 सेकंड।                                                                                                           |
| `ARKVORY_RESTORE_DATABASE_URL`    | पुनर्स्थापना कमांड | सेट नहीं      | पुनर्स्थापना का लक्ष्य डेटाबेस। यह `--database-url` से सुरक्षित है, क्योंकि दूसरे उपयोगकर्ता उसे प्रोसेस सूची में नहीं देख सकते।                                                |

[बैकअप](../operate/backups) देखें।

| `ARKVORY_HUB_PROJECT`        | API          | `arkvory`                  | हब पर प्रोजेक्ट का नाम।                                                                                                                                                                                                    |
| `ARKVORY_UPDATE_CONTROL_DIR` | API          | सेट नहीं                   | वह डायरेक्टरी जिसे API होस्ट के अपडेटर के साथ साझा करता है। इंस्टॉलर इसे सेट करते हैं। इसके बिना कंसोल अपडेट का अनुरोध नहीं कर सकता।                                                                                       |

[अपडेट](../install/updates) देखें।

## लॉगिंग और शटडाउन {#logging-and-shutdown}

| वेरिएबल                    | कौन पढ़ता है      | डिफ़ॉल्ट | अर्थ                                                                                  |
| -------------------------- | ----------------- | -------- | ------------------------------------------------------------------------------------- |
| `ARKVORY_LOG_LEVEL`        | API, वर्कर, एजेंट | `info`   | `debug`, `info`, `warning` या `error`।                                                |
| `ARKVORY_ACCESS_LOG`       | API               | `true`   | `true` हर HTTP अनुरोध के लिए एक JSON पंक्ति लिखता है; `false` इसे बंद करता है।        |
| `ARKVORY_DRAIN_TIMEOUT_MS` | API               | `30000`  | रोकने का सिग्नल मिलने के बाद चल रहे अनुरोधों के पूरे होने के लिए समय, 0–3 600 000 ms। |

## रीड गेटवे {#read-gateways}

इनमें से कोई भी वेरिएबल सेट हो, तो स्लॉट, स्लॉट की संख्या और साझा दर आवश्यक हैं। राइटर भूमिका `api` और स्लॉट `0` इस्तेमाल करता है। हर रीड गेटवे भूमिका `reader` और अपना स्लॉट इस्तेमाल करता है। [रीड गेटवे](../operate/read-gateways) देखें।

| वेरिएबल                                                  | कौन पढ़ता है | डिफ़ॉल्ट | अर्थ                                                                                                |
| -------------------------------------------------------- | ------------ | -------- | --------------------------------------------------------------------------------------------------- |
| `ARKVORY_ROLE`                                           | API          | `api`    | `api` (राइटर) या `reader` (रीड गेटवे)।                                                              |
| `ARKVORY_GATEWAY_SLOTS`                                  | API          | सेट नहीं | डाउनलोड बजट साझा करने वाले प्रोसेस की संख्या, 2–16।                                                 |
| `ARKVORY_GATEWAY_SLOT`                                   | API          | सेट नहीं | इस प्रोसेस का स्लॉट, `0` से स्लॉट की संख्या में से एक घटाकर आने वाली संख्या तक।                     |
| `ARKVORY_SHARED_DOWNLOAD_BYTES_PER_SECOND`               | API          | सेट नहीं | सभी प्रोसेस की कुल डाउनलोड दर। हर स्लॉट को बराबर हिस्सा मिलता है, कम से कम 65 536 बाइट प्रति सेकंड। |
| `ARKVORY_SHARED_DOWNLOAD_BYTES_PER_SECOND_PER_PRINCIPAL` | API          | `0`      | सभी प्रोसेस में एक खाते या कुंजी की कुल डाउनलोड दर; `0` का मतलब कोई सीमा नहीं।                      |

## इंस्टॉलर स्क्रिप्ट {#installer-scripts}

इन वेरिएबल को Linux पर `install.sh` पढ़ता है। Windows पर `install.ps1` इसके बजाय `-Root` और `-Artifact` जैसे पैरामीटर इस्तेमाल करता है।

| वेरिएबल                   | डिफ़ॉल्ट                | अर्थ                                                                                         |
| ------------------------- | ----------------------- | -------------------------------------------------------------------------------------------- |
| `ARKVORY_INSTALL_ROOT`    | `/opt/proanima-arkvory` | इंस्टॉलेशन रूट। नेटिव इंस्टॉलेशन को होम डायरेक्टरी में न रखें।                               |
| `ARKVORY_ARTIFACT_DIR`    | सेट नहीं                | अनपैक की गई रिलीज़ की डायरेक्टरी। स्क्रिप्ट रिलीज़ डाउनलोड करने के बजाय इसे इंस्टॉल करती है। |
| `ARKVORY_RELEASE_VERSION` | नवीनतम स्थिर            | इंस्टॉल करने के लिए सटीक स्थिर संस्करण, जैसे `1.2.3`।                                        |

## इंस्टॉलर द्वारा सेट {#set-by-the-installer}

इंस्टॉलर ये वेरिएबल अपनी सहायक प्रोसेस के लिए सेट करता है। इन्हें खुद सेट न करें।

| वेरिएबल                   | अर्थ                                                                        |
| ------------------------- | --------------------------------------------------------------------------- |
| `ARKVORY_IMAGE`           | वर्तमान रिलीज़ की कंटेनर इमेज, `config/compose.env` में।                    |
| `ARKVORY_SERVICE_WRAPPER` | Windows बैकअप सेवा रैपर का पथ, जो सेवा रुकी होने पर इस्तेमाल होता है।       |
| `ARKVORY_PROTECT_ROOT`    | वह इंस्टॉलेशन रूट जिसके एक्सेस नियम Windows पर सेट किए जाते हैं।            |
| `ARKVORY_ENGINE_USER`     | Docker Desktop वाले Windows पर वर्तमान उपयोगकर्ता को रूट का एक्सेस देता है। |
