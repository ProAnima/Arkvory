# 환경 변수

Arkvory는 이름이 `ARKVORY_`로 시작하는 환경 변수로 구성합니다. 이 페이지는 서버 프로세스, 명령줄 클라이언트, 설치 스크립트가 읽는 모든 변수를 나열합니다.

## 값을 가져오는 위치 {#where-the-values-come-from}

설치 프로그램은 서버 설정을 설치 루트의 `config/runtime.json` 파일 하나에 기록합니다. 각 서비스의 런처가 이 파일을 읽어 값을 API, 워커, 백업 에이전트에 전달합니다. 각 키는 `ARKVORY_`로 시작해야 하며, 각 값은 문자열이어야 합니다.

```json
{
  "ARKVORY_HOST": "127.0.0.1",
  "ARKVORY_PORT": "8080",
  "ARKVORY_CAPACITY_BYTES": "10995116277760",
  "ARKVORY_DATABASE_URL": "postgresql://arkvory:PASSWORD@127.0.0.1:54329/arkvory",
  "ARKVORY_DATA_DIR": "/opt/proanima-arkvory/data",
  "ARKVORY_KEYS_FILE": "/opt/proanima-arkvory/config/keys.json",
  "ARKVORY_MAX_DOWNLOADS": "32"
}
```

이 파일에는 데이터베이스 비밀번호가 들어 있습니다. 설치 프로그램이 설정한 접근 권한을 그대로 유지하세요.

설정을 변경하려면 `config/runtime.json`을 편집하고 서비스를 다시 시작하세요. `arkvory configure` 명령이 해당 설정(HTTPS, 백업 보관소, 미러, 업데이트)을 지원하면 그 명령을 사용하는 것이 좋습니다. 이 명령은 변경 사항을 검사하고, 서비스가 시작되지 않으면 이전 파일을 복원합니다. [구성](../install/configuration)을 참조하세요.

```bash
sudo systemctl restart arkvory-api arkvory-worker arkvory-backup
```

```powershell
Restart-Service Arkvoryapi, Arkvoryworker, Arkvorybackup
```

허용 범위를 벗어난 값은 시작할 때 해당 변수의 이름을 알리는 메시지와 함께 프로세스를 중지시킵니다. 이 경우 Arkvory는 기본값으로 대체하지 않습니다.

"읽는 주체" 열에는 다음 이름을 사용합니다. **API**는 HTTP 서버(읽기 게이트웨이 포함), **워커**는 백그라운드 워커, **에이전트**는 백업 에이전트, **CLI**는 `arkvoryctl`입니다.

## 핵심 설정 {#core}

| 변수                              | 읽는 주체                         | 기본값            | 의미                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| --------------------------------- | --------------------------------- | ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ARKVORY_DATABASE_URL`            | API, 워커, 에이전트, 마이그레이션 | 필수              | PostgreSQL 연결 URL(`postgres://` 또는 `postgresql://`). 설치마다 별도의 데이터베이스를 사용하세요.                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `ARKVORY_DATA_DIR`                | API, 워커, 에이전트               | 필수              | 로컬 스토리지 디렉터리: 스테이징, 콘텐츠, `storage-id` 파일. 네트워크 공유를 사용하지 마세요.                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `ARKVORY_HOST`                    | API                               | `127.0.0.1`       | 수신할 주소. 설치 프로그램은 `127.0.0.1`을 기록합니다. Docker Compose에서는 컨테이너 안에서 `0.0.0.0`이며, 포트는 호스트의 루프백에만 게시됩니다.                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `ARKVORY_PORT`                    | API                               | `8080`            | TCP 포트, 1–65535.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `ARKVORY_WEB_DIR`                 | API                               | `apps/web/public` | 웹 콘솔 파일이 있는 디렉터리. 런처가 시작할 때마다 현재 릴리스로 설정합니다.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `ARKVORY_DATABASE_POOL_SIZE`      | API                               | `20`              | API 쿼리 연결 풀의 크기, 4–200. 장기 세션은 연결 3개짜리 별도 풀을 사용합니다.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `ARKVORY_MODULES_FILE`            | API, 워커, 에이전트               | 설정 안 함        | 내장 모듈을 선택하는 JSON 파일의 절대 경로입니다(예: `{"format": 1, "modules": {"npm": {"enabled": false}}}`). 끌 수 있는 것은 `oci`, `lfs`, `npm`뿐이며 `upack`, `raw`, `local-storage`는 코어입니다. `local-storage` 설정으로 [스토리지 볼륨](../operate/storage#volumes)을 추가합니다. 알 수 없는 모듈이나 필드가 있으면 시작이 중단됩니다. API, 읽기 게이트웨이, 워커, 백업 에이전트는 같은 파일을 읽어야 하며, 계획이 다른 읽기 게이트웨이나 워커는 준비 상태가 되지 않습니다. 설치된 서명 모듈은 이 파일이 활성화할 때만 실행됩니다([모듈](../operate/modules#load)). |
| `ARKVORY_MODULES_DIR`             | API, 워커                         | 런처가 설정       | 서비스가 설치된 서명 모듈을 찾는 설치 루트의 `modules` 디렉터리 절대 경로입니다. 설정하지 않으면(Docker Compose) 서명 모듈을 로드하지 않습니다.                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `ARKVORY_MODULE_REVOCATIONS_FILE` | API, 워커                         | 런처가 설정       | 저장된 모듈 폐기 목록의 절대 경로로, 설치 루트의 `config/module-revocations.json`입니다.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |

## 스토리지와 제한 {#storage-and-limits}

| 변수                              | 읽는 주체           | 기본값         | 의미                                                                                                                                                                |
| --------------------------------- | ------------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ARKVORY_CAPACITY_BYTES`          | API, 워커           | 10 TiB         | 예약된 모든 콘텐츠(게시된 콘텐츠, 완료되지 않은 업로드, 정리를 기다리는 콘텐츠)에 대한 상한(바이트). 디스크 검사가 아닙니다. 워커는 미러 복사에만 이 값을 읽습니다. |
| `ARKVORY_STORAGE_RESERVE_BYTES`   | API, 워커, 에이전트 | `1073741824`   | 업로드가 절대 사용하지 않는 여유 공간(바이트). 데이터베이스, 로그, 시스템을 위해 남겨 둡니다. `0`이면 예약을 끕니다.                                                |
| `ARKVORY_STORAGE_RESERVE_INODES`  | API, 워커           | `100000`       | 각 볼륨에서 쓰기가 절대 사용하지 않는 여유 inode 수. NTFS처럼 inode 수가 없는 파일 시스템은 이 검사를 건너뜁니다. `0`이면 검사를 끕니다.                            |
| `ARKVORY_REHOME_BYTES_PER_SECOND` | 워커                | `0`(제한 없음) | [볼륨 간 이동](../operate/storage#rehome)의 복사 속도(초당 바이트).                                                                                                 |
| `ARKVORY_MAX_OBJECT_BYTES`        | API                 | 약 10 TiB      | 가장 큰 객체의 크기(바이트). 허용되는 최댓값은 1 GiB 파트 10 000개입니다. 파일 크기를 제한하려면 더 낮은 값을 설정하세요.                                           |

## 전송과 대역폭 {#transfers-and-bandwidth}

이 제한은 API 프로세스 하나에 적용됩니다. 속도의 단위는 초당 바이트입니다. `0`은 제한 없음을 뜻하고, 다른 값은 65 536에서 1 TiB 사이여야 합니다.

| 변수                                              | 읽는 주체 | 기본값                                        | 의미                                                                                                                                                                                                                                                                                                                                                                 |
| ------------------------------------------------- | --------- | --------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ARKVORY_MAX_UPLOADS`                             | API       | `8`                                           | 동시에 실행되는 업로드 수, 1–32.                                                                                                                                                                                                                                                                                                                                     |
| `ARKVORY_MAX_DOWNLOADS`                           | API       | `16`                                          | 동시에 실행되는 다운로드 수, 1–256.                                                                                                                                                                                                                                                                                                                                  |
| `ARKVORY_MAX_UPLOADS_PER_PRINCIPAL`               | API       | `4`                                           | 계정 또는 키 하나의 동시 업로드 수. 전체 업로드 한도를 넘을 수 없습니다.                                                                                                                                                                                                                                                                                             |
| `ARKVORY_MAX_DOWNLOADS_PER_PRINCIPAL`             | API       | `4`                                           | 계정 또는 키 하나의 동시 다운로드 수. 전체 다운로드 한도를 넘을 수 없습니다.                                                                                                                                                                                                                                                                                         |

## 네트워크, HTTPS, 브라우저 {#network-https-and-browsers}

| 변수                         | 읽는 주체 | 기본값     | 의미                                                                                                                 |
| ---------------------------- | --------- | ---------- | -------------------------------------------------------------------------------------------------------------------- |
| `ARKVORY_TLS_CERT_FILE`      | API       | 설정 안 함 | 내장 HTTPS용 PEM 인증서(체인 포함). 키 파일과 함께 설정하세요.                                                       |
| `ARKVORY_TLS_KEY_FILE`       | API       | 설정 안 함 | 비밀번호가 없는 PEM 개인 키.                                                                                         |
| `ARKVORY_TLS_MIN_VERSION`    | API       | `TLSv1.2`  | `TLSv1.2` 또는 `TLSv1.3`.                                                                                            |
| `ARKVORY_TLS_RELOAD_SECONDS` | API       | `300`      | 갱신된 인증서 파일을 읽는 주기: 30–86 400초. `0`이면 시작할 때만 읽습니다.                                           |
| `ARKVORY_CORS_ORIGINS`       | API       | 비어 있음  | 다른 주소의 콘솔을 위한 브라우저 출처의 쉼표 구분 목록(최대 16개). HTTPS만 허용하며, 루프백에서는 HTTP도 허용합니다. |
| `ARKVORY_TRUSTED_PROXIES`    | API       | 비어 있음  | 리버스 프록시 주소(IP 또는 CIDR) 최대 32개. 이 주소만 `X-Forwarded-For`로 클라이언트 주소를 설정할 수 있습니다.      |

내장 HTTPS는 네이티브 설치용입니다. Docker Compose에서는 리버스 프록시를 사용하세요. [HTTPS](../install/https)를 참조하세요.

## ID와 키 {#identity-and-keys}

| 변수                         | 읽는 주체 | 기본값 | 의미                                                                                                    |
| ---------------------------- | --------- | ------ | ------------------------------------------------------------------------------------------------------- |
| `ARKVORY_KEYS_FILE`          | API, 워커 | 필수   | 복구 키와 상태 확인 키 같은 파일 키가 들어 있는 JSON 파일. 키 자체가 아니라 SHA-256 해시를 저장합니다.  |

## 읽기 게이트웨이 {#read-gateways}

이 변수 중 하나라도 설정하면 슬롯, 슬롯 수, 공유 속도가 필요합니다. 쓰기 서버는 역할 `api`와 슬롯 `0`을 사용합니다. 각 읽기 게이트웨이는 역할 `reader`와 자신의 슬롯을 사용합니다. [읽기 게이트웨이](../operate/read-gateways)를 참조하세요.

| 변수                                                     | 읽는 주체 | 기본값     | 의미                                                                                      |
| -------------------------------------------------------- | --------- | ---------- | ----------------------------------------------------------------------------------------- |
| `ARKVORY_ROLE`                                           | API       | `api`      | `api`(쓰기 서버) 또는 `reader`(읽기 게이트웨이).                                          |
| `ARKVORY_GATEWAY_SLOTS`                                  | API       | 설정 안 함 | 다운로드 예산을 공유하는 프로세스 수, 2–16.                                               |
| `ARKVORY_GATEWAY_SLOT`                                   | API       | 설정 안 함 | 이 프로세스의 슬롯, `0`부터 슬롯 수 − 1까지.                                              |
| `ARKVORY_SHARED_DOWNLOAD_BYTES_PER_SECOND`               | API       | 설정 안 함 | 모든 프로세스의 전체 다운로드 속도. 각 슬롯은 같은 몫(최소 초당 65 536바이트)을 받습니다. |
| `ARKVORY_SHARED_DOWNLOAD_BYTES_PER_SECOND_PER_PRINCIPAL` | API       | `0`        | 계정 또는 키 하나의 모든 프로세스에 걸친 전체 다운로드 속도. `0`은 제한 없음을 뜻합니다.  |

## 설치 스크립트 {#installer-scripts}

이 변수는 Linux의 `install.sh`가 읽습니다. Windows의 `install.ps1`은 대신 `-Root`, `-Artifact` 같은 매개 변수를 사용합니다.

| 변수                      | 기본값                  | 의미                                                                                           |
| ------------------------- | ----------------------- | ---------------------------------------------------------------------------------------------- |
| `ARKVORY_INSTALL_ROOT`    | `/opt/proanima-arkvory` | 설치 루트. 네이티브 설치를 홈 디렉터리에 두지 마세요.                                          |

## 설치 프로그램이 설정하는 변수 {#set-by-the-installer}

설치 프로그램은 자체 도우미 프로세스를 위해 이 변수를 설정합니다. 직접 설정하지 마세요.

| 변수                      | 의미                                                                      |
| ------------------------- | ------------------------------------------------------------------------- |
| `ARKVORY_IMAGE`           | `config/compose.env`에 있는 현재 릴리스의 컨테이너 이미지.                |
| `ARKVORY_SERVICE_WRAPPER` | 서비스가 중지된 상태에서 사용하는 Windows 백업 서비스 래퍼의 경로.        |
