# حزم Unity وnpm

كل مستودع Arkvory هو سجل متوافق مع npm على `https://<host>/npm/<repository>/`. يقرأه Unity Package Manager كسجل مقيّد بنطاقات، وينشر إليه `npm` ويثبّت منه. تستخدمه الاستوديوهات لحزم SDK والأدوات والوحدات التي تشترك فيها مشروعات Unity متعددة، ولكل منها إصدارها الخاص.

أرشيفات الحزم مُخرَجات عادية، لذلك تنطبق عليها أذونات المستودع وحصص التخزين وفحوص SHA-256 والنسخ الاحتياطية والمرايا.

## قبل البدء {#before-you-start}

تحتاج إلى:

- عنوان الخادم عبر HTTPS (راجع [HTTPS](../install/https)).
- مستودع، مثل `games`. عنوان سجله هو `https://arkvory.example/npm/games/`.
- مفتاح. يستخدم المطوّرون رمز وصول شخصيًا بالنطاق `read`. ويستخدم وكلاء البناء الذين ينشرون رمزًا شخصيًا بالنطاق `read-write` أو مفتاح خدمة. راجع [الحسابات والمفاتيح](../use/accounts).

يرسل Arkvory عنوان كل أرشيف حزمة إلى العميل في بيانات الحزمة. يُبنى العنوان من اسم المضيف الذي استخدمه العميل. عندما ينهي وكيل عكسي اتصال HTTPS، يجب أن يمرّر الترويسة `Host` ويرسل `X-Forwarded-Proto: https`، كما في مثال nginx في تعليمات التثبيت. وإلا يتلقى العميل عناوين `http://` لأرشيفات الحزم.

## إضافة السجل إلى مشروع Unity {#unity-manifest}

1. افتح `Packages/manifest.json` الخاص بالمشروع وأضف سجلًا مقيّدًا بنطاقات:

```json
{
  "scopedRegistries": [
    {
      "name": "Arkvory",
      "url": "https://arkvory.example/npm/games/",
      "scopes": ["com.proanima"]
    }
  ],
  "dependencies": {
    "com.proanima.tools": "1.2.0"
  }
}
```

2. أعطِ Unity المفتاح. لا تضعه في المشروع. أنشئ الملف `.upmconfig.toml` في مجلد المستخدم (`%USERPROFILE%\.upmconfig.toml` على Windows، و`~/.upmconfig.toml` على macOS وLinux):

```toml
[npmAuth."https://arkvory.example/npm/games/"]
token = "<your Arkvory key>"
alwaysAuth = true
```

3. أعد تشغيل Unity. في نافذة Package Manager، افتح **سجلاتي** لرؤية حزم السجل.

ملاحظات:

- تمثل `scopes` بادئات أسماء الحزم. يأخذ Unity الحزم التي تبدأ أسماؤها بنطاق من Arkvory، ويأخذ جميع الحزم الأخرى من سجل Unity.
- يجب أن يطابق العنوان في `.upmconfig.toml` قيمة `url` في ملف البيان، بما في ذلك الشرطة المائلة النهائية.
- الإعداد `alwaysAuth = true` مطلوب. لا يرسل السجل تحدي تسجيل دخول، لذلك يجب أن يرسل Unity الرمز مع كل طلب.
- أسماء حزم Unity أسماء نطاقات معكوسة بأحرف صغيرة، مثل `com.company.package`. لا يدعم Unity الأسماء التي تتضمن `@scope/`.

أدرج `Packages/manifest.json` في إيداع مع المشروع. يحتفظ كل مطوّر بملف `.upmconfig.toml` خاص به.

## نشر حزمة {#publish}

الحزمة مجلد يحتوي على `package.json` في أعلاه. انشرها باستخدام `npm`.

1. في مجلد الحزمة، أنشئ ملف `.npmrc`:

```ini
registry=https://arkvory.example/npm/games/
//arkvory.example/npm/games/:_authToken=${ARKVORY_TOKEN}
```

2. اضبط المفتاح في البيئة وانشر:

```bash
export ARKVORY_TOKEN="$(cat ~/.arkvory/key)"
npm publish
```

```powershell
$env:ARKVORY_TOKEN = (Get-Content C:\Private\arkvory.key -Raw).Trim()
npm publish
```

يجب أن يبدأ السطر الذي يحتوي على `_authToken` بعنوان السجل من دون `https:`. لا تضع المفتاح في `.npmrc`: يستبدل npm المتغير `${ARKVORY_TOKEN}` بقيمته من البيئة.

بدلًا من سطر `registry` في `.npmrc`، يمكنك ضبط السجل في `package.json` الخاص بالحزمة:

```json
{
  "name": "com.proanima.tools",
  "version": "1.2.0",
  "publishConfig": { "registry": "https://arkvory.example/npm/games/" }
}
```

ما الذي يتحقق منه السجل:

- **الاسم والإصدار.** يجب أن يطابق `name` و`version` في `package.json` داخل الأرشيف الاسم والإصدار المنشورين. يتبع الإصدار SemVer 2.0.0، مثل `1.2.0` أو `2.0.0-beta.1`. يقرأ السجل بيانات الإصدار من هذا الملف، لا من JSON الذي يرسله العميل.
- **المجاميع الاختبارية.** يجب أن يطابق الطول و`shasum` و`integrity` التي يعلنها العميل البايتات. يُرجع عدم التطابق `422 integrity_mismatch`.
- **أرشيف الحزمة.** يجب أن يحتوي على `<folder>/package.json`، كما ينشئه `npm pack`. يُرفض وجود `package.json` ثانٍ في الأرشيف، لأن npm والسجل قد يقرآن ملفين مختلفين.
- **الإصدار غير قابل للتغيير.** ينجح نشر الأرشيف نفسه مجددًا ولا يغيّر شيئًا (`200`). يُرجع محتوى مختلف لإصدار موجود الحالة `409` مع السبب `version_exists`. انشر الإصلاح كالإصدار التالي.

يقرأ `npm publish` الحزمة من السجل قبل نشرها، لذلك امنح مفتاح النشر `content.read` و`artifact.list` إضافة إلى `upload.create`. راجع [الأذونات](#permissions).

يصبح الإصدار متاحًا فور عودة `npm publish`. يُخزَّن أرشيف الإصدار كمُخرَج باسم `<name>-<version>.tgz` مع التسمية `npm`. للاسم الذي يتضمن نطاقًا، يتحول `@team/util` إلى `util-<version>.tgz`.

## تثبيت الحزم {#install}

في Unity، أضف الاعتمادية إلى ملف البيان أو اختر الحزمة في نافذة Package Manager ضمن **سجلاتي**.

بالنسبة إلى npm، اضبط السجل في `.npmrc` الخاص بالمشروع أو بالمستخدم. الاختيار المعتاد هو سجل لنطاق واحد، لأن Arkvory لا يمرّر الطلبات إلى سجل npm العام:

```ini
@team:registry=https://arkvory.example/npm/games/
//arkvory.example/npm/games/:_authToken=${ARKVORY_TOKEN}
```

```bash
npm install @team/util
npm view @team/util versions
npm search tools
```

إذا وجّهت `registry=` إلى Arkvory للمشروع بأكمله، يبحث npm فيه عن كل حزمة، بما فيها الحزم العامة مثل `lodash`، ويفشل بالحالة `404`. استخدم سجلًا مقيّدًا بنطاقات أو مشروعًا لا يحتوي إلا على حزمك الخاصة.

يتحقق npm من `dist.integrity` أثناء التثبيت ويكتب عنوان السجل في `package-lock.json`.

## الإصدارات ووسوم dist-tags {#versions-and-tags}

وسم dist-tag اسم قابل للنقل يشير إلى إصدار. يضبط `npm publish` الوسم `latest` على الإصدار الجديد. تساعد الوسوم الأخرى على فصل قنوات الإصدار.

```bash
npm publish --tag beta
npm dist-tag add com.proanima.tools@1.3.0 latest
npm dist-tag ls com.proanima.tools
npm dist-tag rm com.proanima.tools beta
```

```bash
npm install com.proanima.tools@beta
```

| القاعدة         | القيمة                                                                     |
| --------------- | -------------------------------------------------------------------------- |
| اسم الوسم       | يبدأ بحرف. أحرف وأرقام و`.` و`_` و`-`. حتى 64 محرفًا.                       |
| الوسوم المحظورة | اسم يشبه إصدارًا (`v1` و`v2.0`)، و`x` أو `X`                                |
| `latest`        | يشير دائمًا إلى إصدار. يمكن نقله ولا يمكن إزالته (`409`).                   |
| نقل وسم         | `npm dist-tag add` أو النشر مع `--tag`. يجب أن يكون الإصدار الجديد موجودًا. |

الوسم مجرد اسم: لا يحذف الإصدارات الأخرى ولا يخفيها.

لا توجد طريقة لإزالة إصدار منشور. راجع [الميزات غير المدعومة](#not-supported).

## البحث {#search}

تستخدم قائمة **سجلاتي** في Unity و`npm search` عنوان البحث `/-/v1/search`. يعثر البحث على الحزم التي يحتوي اسمها أو وصفها على النص، بصرف النظر عن حالة الأحرف، وعلى الحزم التي تملك النص ككلمة مفتاحية كاملة. من دون نص، يسرد جميع الحزم.

- يُرجع سطرًا واحدًا لكل حزمة: الإصدار الذي يحمل الوسم `latest`، أو أحدث إصدار إن لم يوجد.
- تُرتَّب النتائج حسب الاسم. لا يوجد ترتيب حسب الشعبية.
- القيمة الافتراضية لـ`size` هي 20، وحدها الأقصى 250. و`from` هو الإزاحة.

```bash
curl -fsS -H "Authorization: Bearer $ARKVORY_TOKEN" \
  "https://arkvory.example/npm/games/-/v1/search?text=tools&from=0&size=20"
```

لقراءة حزمة مباشرة، اطلب اسمها. يمكن إرسال `@scope/name` بصيغة `@scope%2fname`:

```bash
curl -fsS -H "Authorization: Bearer $ARKVORY_TOKEN" https://arkvory.example/npm/games/com.proanima.tools
```

تسرد الاستجابة كل إصدار مع محتويات `package.json` الخاص به (بما فيها الحقلان `unity` و`displayName` اللذان يقرؤهما Unity)، ووسوم dist-tags وأوقات النشر. يحتوي `dist` على `tarball` و`shasum` ‏(SHA-1) و`integrity` ‏(SHA-512).

## الأسماء والحدود {#limits}

| العنصر                      | القاعدة                                                                                                                                                    |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| اسم الحزمة                  | أحرف صغيرة وأرقام و`.` و`_` و`~` و`-`، ويبدأ بحرف أو رقم. حتى 214 محرفًا. يُسمح بـ`@scope/name` لـnpm.                                                       |
| الإصدار                     | SemVer 2.0.0، حتى 256 محرفًا                                                                                                                                |
| `package.json` داخل الأرشيف | حتى 256 KiB. تأتي بيانات جميع الإصدارات في استجابة واحدة، لذا أبقِ حجمه صغيرًا.                                                                              |
| أرشيف الحزمة                | حتى الحد الأقصى لحجم الكائن في التثبيت، `ARKVORY_MAX_OBJECT_BYTES` (نحو 10 TiB افتراضيًا). يُرفض أرشيف يتجاوز حجمه بعد الفك 100 ضعف حجمه مضافًا إليها 64 MiB. |
| بقية طلب النشر              | حتى 8 MiB من JSON، بعمق تداخل لا يزيد على 64 مستوى. يُقرأ أرشيف الحزمة كتدفق ولا يُحتفظ به في الذاكرة.                                                       |
| طلب نشر واحد                | يجب أن ينتهي خلال 30 دقيقة، وألا يتوقف مؤقتًا لأكثر من 30 ثانية (`ARKVORY_UPLOAD_DEADLINE_MS` و`ARKVORY_UPLOAD_IDLE_TIMEOUT_MS`)                            |
| عمليات الرفع المتزامنة      | 8 لكل خادم و4 لكل مفتاح افتراضيًا. يتوقف الطلب المنتظر عن الانتظار بعد 20 ثانية.                                                                            |
| نص البحث                    | حتى 256 محرفًا                                                                                                                                              |

عملية `npm publish` طلب واحد، وتبدأ مجددًا من البايت الأول بعد فشل. للحزم بحجم عدة غيغابايتات، ارفع الملف باستخدام [`arkvoryctl`](./cli) كمُخرَج أو [ملف خام](./raw-files). من الأفضل وضع الأصول الثنائية الكبيرة التي تتغير كثيرًا في [Git LFS](./git-lfs)؛ وأبقِ الشيفرة والموارد المستقرة في الحزم.

توجد حدود الخادم في [متغيرات البيئة](../reference/environment#transfers-and-bandwidth).

## الأذونات {#permissions}

تحصل الرموز الشخصية ومفاتيح الملفات على حق القراءة أو الكتابة في المستودع. وتحصل مفاتيح الخدمة على إجراءات محددة.

| العملية                              | إجراءات مفتاح الخدمة | الرمز الشخصي أو مفتاح الملف          |
| ------------------------------------ | -------------------- | ------------------------------------ |
| التثبيت: قراءة حزمة وتنزيل أرشيفها   | `content.read`       | حق القراءة                           |
| البحث وسرد وسوم dist-tags            | `artifact.list`      | حق القراءة                           |
| النشر وإضافة وسوم dist-tags وإزالتها | `upload.create`      | حق الكتابة، ونطاق الرمز `read-write` |

يحتاج المطوّر الذي لا يفعل إلا تثبيت الحزم إلى رمز بالنطاق `read`. ويحتاج وكيل البناء الذي ينشر إلى `upload.create` و`content.read` و`artifact.list`. لا يستطيع أحد حذف إصدار منشور.

## بوابات القراءة والمرايا {#read-gateways-and-mirrors}

- تقدّم [بوابة القراءة](../operate/read-gateways) التثبيت والبحث، لأنهما طلبات `GET`. يحصل النشر على `405`.
- تحتفظ [المرآة](../operate/mirrors) بإصدارات مصدرها ووسومه. يعمل التثبيت والبحث. يُرفض النشر بالحالة `409` والسبب `mirror_read_only`. تشير عناوين أرشيفات الحزم في بيانات المرآة إلى المرآة نفسها.

لاستخدام مرآة في Unity، ضع عنوان المرآة في `url` ومفتاحها في `.upmconfig.toml`.

## الميزات غير المدعومة {#not-supported}

- إزالة إصدار (`npm unpublish`). تثبّت المشروعات إصدارات محددة، وستعطّل الإزالة عمليات بنائها. انشر إصدارًا مصححًا وانقل الوسم بدلًا من ذلك.
- `npm deprecate` و`npm login` و`npm owner` و`npm access` وأوامر الإدارة الأخرى. تحصل الطلبات التي تغيّر البيانات على مسارات أخرى على `405` مع "This registry supports publish, install and dist-tags". أنشئ رمزًا في وحدة التحكم وضعه في `.npmrc` بدلًا من `npm login`.
- قائمة جميع الحزم على `/-/all`، و`npm audit`.
- وكيل إلى السجلات العامة. يخزّن Arkvory حزمك الخاصة. تُجلب حزم npmjs.com أو سجل Unity من هناك.
- ترتيب نتائج البحث حسب الأفضلية.
- قسم للحزم في وحدة التحكم. تظهر أرشيفات الحزم في [[ui:catalog]] كمُخرَجات بالتسمية `npm`.

## استكشاف الأخطاء وإصلاحها {#troubleshooting}

الأخطاء بالصيغة `{"error": "...", "code": "...", "request_id": "..."}`. يطبع `npm` الحقل `error`. أعطِ المسؤول `request_id` للعثور على الطلب في سجل الخادم.

| العَرَض                                                    | السبب                                                          | الإجراء                                                                                                                                                                                        |
| -------------------------------------------------------- | -------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `401` في Unity أو npm                                    | لم يرسل العميل المفتاح، أو المفتاح غير صحيح أو منتهٍ أو مُبطل    | في Unity، تحقق من تطابق العنوان في `.upmconfig.toml` مع `url` في ملف البيان ومن `alwaysAuth = true`. في npm، تحقق من أن سطر `_authToken` يبدأ بالمضيف والمسار نفسيهما الموجودين في `registry`. |
| `403` عند النشر                                          | نطاق الرمز هو `read`، أو يفتقر المفتاح إلى `upload.create`     | استخدم مفتاحًا بحق الكتابة                                                                                                                                                                      |
| `404` لحزمة                                              | لا توجد هذه الحزمة في هذا المستودع، أو لا يرى المفتاح المستودع | تحقق من المستودع في العنوان ومن الاسم. لحزمة Unity، تحقق من أن اسمها يبدأ بنطاق من `scopes`.                                                                                                   |
| `404` لحزمة عامة                                         | يوجّه `registry=` جميع الحزم إلى Arkvory                        | استخدم `@scope:registry=`                                                                                                                                                                      |
| `409` مع `version_exists`                                | الإصدار موجود بمحتوى آخر                                       | انشر إصدارًا جديدًا                                                                                                                                                                              |
| `409` مع `state_conflict`                                | حاولت إزالة `latest`                                           | انقل `latest` إلى إصدار آخر بدلًا من ذلك                                                                                                                                                        |
| `409` مع `mirror_read_only`                              | المستودع مرآة                                                  | انشر إلى الخادم الرئيسي                                                                                                                                                                        |
| `422` مع `integrity_mismatch`                            | تختلف البايتات عن `shasum` أو `integrity` المُعلنين             | أنشئ الأرشيف وانشر مجددًا. تحقق من عدم وجود وكيل يغيّر الجسم.                                                                                                                                    |
| `400` مع "package.json names another package or version" | يختلف `package.json` داخل الأرشيف عن الاسم أو الإصدار المنشور  | شغّل `npm publish` من بناء نظيف للحزمة                                                                                                                                                          |
| `400` مع "Only publishing a new version is supported"    | أرسل الأمر حزمة معدّلة، مثل `npm deprecate`                     | هذه الأوامر غير مدعومة                                                                                                                                                                         |
| `405`                                                    | لا يدعم هذا السجل الأمر                                        | راجع [الميزات غير المدعومة](#not-supported)                                                                                                                                                    |
| `507`                                                    | بُلغت حصة تخزين المستودع أو سعة التثبيت                         | حرّر مساحة أو اطلب حصة تخزين أكبر                                                                                                                                                               |
| `503`                                                    | عدد كبير جدًا من عمليات الرفع المتزامنة                         | انتظر وأعد المحاولة                                                                                                                                                                            |
| يُنزَّل أرشيف الحزمة من `http://` ويفشل                     | لا يرسل الوكيل `X-Forwarded-Proto: https`                      | أصلح الوكيل كما هو موضح في [قبل البدء](#before-you-start)                                                                                                                                      |
