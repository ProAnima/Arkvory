# وكلاء الذكاء الاصطناعي

يمكن لعميل وكيل ذكاء اصطناعي يدعم بروتوكول سياق النموذج (MCP)، مثل Claude Code، العمل مع Arkvory من خلال `arkvoryctl mcp`. يشغّل العميل الأمر ويتواصل معه عبر الإدخال والإخراج القياسيين، دون فتح منفذ شبكة. وتعلّم مهارة الوكيل كيفية تنفيذ مسارات العمل بأمان باستخدامه.

## قبل البدء {#before}

1. ثبّت [عميل سطر الأوامر](../protocols/cli) على الجهاز الذي يعمل عليه الوكيل.
2. أنشئ للوكيل مفتاح خدمة لا يتيح الوصول إلا إلى المستودعات والإجراءات اللازمة. احفظه في ملف لا يستطيع قراءته سواك.
3. أضف ملف تعريف يشير إلى ملف المفتاح وتحقّق منه:

```bash
arkvoryctl profile add agent --server https://arkvory.example --token-file ~/.config/arkvory/agent.key --repository builds
arkvoryctl doctor --profile agent
```

لا تلصق المفتاح في المحادثة أو في وسيطة أمر أو ملف مشروع. لا يرى الوكيل المفتاح، إذ لا تتضمنه النتائج أو الأخطاء.

## توصيل خادم MCP {#connect}

```bash
claude mcp add arkvory -- arkvoryctl mcp --profile agent --root ~/work
```

من دون `--write`، يعمل الخادم للقراءة فقط: يستطيع الوكيل سرد المستودعات والبحث فيها جميعًا، وقراءة المُخرَجات والحزم والملفات حسب المسار وتدفّق التغييرات وحالة التثبيت، وتنزيل المُخرَجات. لا تُعرض الأدوات التي لا يسمح المفتاح باستخدامها. يجب أن يدعم العميل MCP 2025-06-18 أو أحدث.

## السماح بالكتابة {#write}

للكتابة إعداد منفصل. حدّد المستودعات التي يجوز للوكيل الكتابة إليها:

```bash
claude mcp add arkvory-publish -- arkvoryctl mcp --profile agent --root ~/work --write --write-repositories builds
```

| الأداة                    | وظيفتها                                                                               |
| ------------------------- | ------------------------------------------------------------------------------------- |
| `arkvory_upload`          | ترفع ملفًا كمُخرَج جديد أو كمراجعة تالية لمسار ملف                                       |
| `arkvory_publish_package` | ترفع UPack وتسجّله كإصدار حزمة                                                         |
| `arkvory_promote`         | تضيف مرحلة؛ وعند تحديد `sha256`، لا تطبّقها إلا على المُخرَج المطابق لتلك البايتات تمامًا |
| `arkvory_stage_remove`    | تزيل مرحلة مع الإبقاء على المُخرَج                                                      |
| `arkvory_annotate`        | تستبدل التسميات وبيانات التعريف عند المراجعة التي قرأها الوكيل                        |

- تُرفض الكتابة إلى مستودع غير مدرج في `--write-repositories` قبل إرسال أي شيء (`repository_not_allowed`). ويتحقّق الخادم أيضًا من أذونات المفتاح.
- لا يمكن حذف أي شيء أو استعادته، ولا تُنشأ روابط تنزيل. تظل هذه مهامًا ينفّذها شخص في وحدة التحكم.
- يوجّه الخادم الوكيل إلى وصف كل عملية كتابة وانتظار تأكيدك. وقد يطلب عميل MCP التأكيد قبل كل استدعاء أيضًا.
- يمكن استئناف الرفع: بعد فشل العملية، يكرّر الوكيل الاستدعاء نفسه، فيُعاد المُخرَج نفسه بدل إنشاء مُخرَج ثانٍ. تتضمن النتيجة SHA-256 للملف الذي جرت قراءته.

## الملفات والحدود {#files}

- يقرأ الوكيل الملفات المحلية ويكتبها فقط داخل `--root`، الذي يكون افتراضيًا الدليل الحالي. يُرفض أي مسار يؤدي إلى خارجه، بما في ذلك عبر رابط (`path_outside_root`).
- لا يظهر الملف المنزّل إلا بعد التحقّق من حجمه ومن SHA-256. ولا يُستبدل ملف موجود إلا إذا طلب الوكيل ذلك.
- لا يُرفع ملف يحتوي على المفتاح مطلقًا (`source_contains_credential`). كما لا تُقرأ ملفات arkvoryctl الخاصة ولا تُستبدل، حتى داخل `--root`، ومنها ملفات التعريف وملفات المفاتيح ونقاط استئناف الرفع (`private_path`).
- لا تتجاوز النتيجة الواحدة `--max-output-bytes`، وقيمته الافتراضية 64 KiB وحدّه الأقصى 1 MiB، ولا تتجاوز 100 عنصر. لطلب المزيد، يمرّر الوكيل قيمة `next` في `after`.

## تثبيت المهارة {#skill}

المهارة مجموعة تعليمات للوكيل تشرح كيفية البحث والتحقّق من التنزيلات والنشر والترقية وقراءة رموز الأخطاء، وما يجب عليه ألا يفعله مطلقًا. وهي مرفقة بالعميل:

```bash
arkvoryctl skill install
```

تُثبَّت المهارة في `~/.claude/skills/arkvory`. استخدم `--target DIR` لتثبيتها داخل مشروع، مثل `.claude/skills/arkvory`. يؤدي تكرار الأمر إلى تحديث الملفات التي لم تعدّلها. أما الملفات التي عدّلتها فتبقى محفوظة: يتوقف الأمر دون تغيير أي شيء ما لم تضف `--force`.

## الأمان {#safety}

- يكتب أشخاص آخرون الأسماء والتسميات وبيانات التعريف والتعليقات التي تظهر في النتائج. يعاملها الوكيل كبيانات ولا يتبع أي تعليمات واردة فيها.
- افصل إعداد القراءة فقط عن إعداد الكتابة، ولا تسمح بالكتابة إلا إلى المستودعات التي تتطلبها المهمة.
- استخدم مفتاحًا مخصصًا بصلاحيات محدودة، وأبطله من وحدة التحكم عندما لا يعود الوكيل بحاجة إليه.

## استكشاف الأخطاء وإصلاحها {#troubleshooting}

| الخطأ                    | السبب والحل                                                                                                                                                                                     |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| لا توجد أدوات كتابة      | شُغّل الخادم دون `--write`، أو أن المفتاح يفتقر إلى الإذن.                                                                                                                                        |
| `repository_not_allowed` | المستودع غير مدرج في `--write-repositories`. عدّل إعداد MCP.                                                                                                                                     |
| `forbidden`              | المفتاح يفتقر إلى الإذن. شغّل `arkvoryctl doctor` لعرض الأذونات.                                                                                                                                 |
| `path_outside_root`      | الملف خارج `--root` أو ليس ملفًا عاديًا.                                                                                                                                                          |
| `state_locked`           | لا تزال عملية الرفع نفسها تعمل في استدعاء آخر. بعد تعطل العملية، تأكّد من عدم وجود `arkvoryctl mcp` يرفع ذلك الملف، ثم احذف ملف `.lock` من `mcp-uploads` داخل دليل CLI، وهو `~/.config/arkvory`. |
| `skill_modified`         | عدّلت ملفًا من ملفات المهارة. احتفظ بنسختك أو أعد تشغيل `arkvoryctl skill install` مع `--force`.                                                                                                  |
