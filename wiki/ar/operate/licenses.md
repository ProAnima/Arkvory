# التراخيص

تعمل نواة Arkvory المجانية دون ترخيص لوحدة مدفوعة. يتيح الترخيص ميزات ProAnimaStudio المدفوعة، بما فيها [Arkvory Pro](modules#pro). لا يجعل انتهاء الصلاحية بيانات Pro الموجودة غير قابلة للقراءة؛ تستخدم عمليات الرفع الجديدة تخزين النواة وعمليات النقل العادية عندما لا تتوفر الميزات المدفوعة. وحتى تفعّل ترخيصاً، لا يرسل Arkvory أي شيء متعلق بالتراخيص إلى أي جهة.

تُنفّذ أوامر هذه الصفحة على مضيف التثبيت، بصلاحيات root على Linux أو مسؤول على Windows. لا تحمّل تثبيتات Docker Compose الوحدات، ولذلك ترفض هذه الأوامر.

## التفعيل عبر الإنترنت {#activate}

1. احفظ مفتاح الترخيص من موقع ProAnimaStudio في ملف لا يستطيع قراءته غيرك، مثل `/root/arkvory.key`.
2. فعّل الترخيص:

   ```bash
   sudo arkvory license activate --key-file /root/arkvory.key --root /opt/proanima-arkvory
   ```

3. احذف ملف المفتاح المحلي بعد التفعيل. احتفظ بإمكانية الوصول إلى مفتاح الترخيص في حسابك: فقد يتطلب الاسترداد استخدامه مجدداً.

يرسل Arkvory الطلب إلى مركز التثبيت (العنوان في `config/hub.json`، وهو نفسه المستخدم للتحديثات) عبر HTTPS مع التحقق من الشهادة. ولا يقبل الاستجابة إلا إذا كانت موقّعة بمفتاح ترخيص ProAnimaStudio ولهذا التثبيت ولهذا الطلب. يُرفض المفتاح الذي يتضمن خطأً كتابياً قبل إرسال أي شيء. لا يستهلك تفعيل التثبيت نفسه بالمفتاح نفسه مجدداً موضعاً إضافياً في الترخيص.

### ما يُرسل {#sent}

| الطلب   | المحتوى                                                                                                          |
| ------- | ---------------------------------------------------------------------------------------------------------------- |
| التفعيل | مفتاح الترخيص، ومعرّف التثبيت، وقيمة عشوائية، وإصدار Arkvory، ومعرّفات الوحدات المدفوعة المثبّتة وإصداراتها، والوقت |
| التجديد | معرّف التفعيل وسره، وقيمة عشوائية، والرقم التسلسلي، والإصدارات                                                    |

لا يُرسل أبداً اسم المرخّص له، أو أسماء الأشخاص، أو العناوين، أو تفاصيل الجهاز، أو كميات البيانات، أو أسماء المستودعات، أو المحتوى، أو بيانات التعريف، أو إحصاءات الاستخدام. لا يضيف تعطيل الإحصاءات أي شيء هنا ولا يزيله. عند تعطيل المركز (`--hub-off`)، استخدم [التفعيل دون اتصال](#offline).

### ما يُحتفظ به {#kept}

- الرمز: مستند المركز الموقّع، في قاعدة البيانات والنسخ الاحتياطية.
- سر التفعيل: ملف في `config/licenses/` لا يمكن قراءته إلا لحساب الخدمات. ولا يوجد أبداً في قاعدة البيانات أو السجلات أو نسخة احتياطية.
- مفتاح الترخيص: لا يُحفظ في أي مكان.

## التحقق من الحالة {#status}

```bash
sudo arkvory license status --root /opt/proanima-arkvory
```

أضف `--json` للبرامج النصية. يرى المسؤول العام المعلومات نفسها عبر `GET /api/v1/system/license` ([المرجع](../api/reference/system#getSystemLicense)). يتحقق Arkvory مجدداً من كل مستند مخزّن في كل مرة؛ يكون المستند الذي لم توقّعه ProAnimaStudio بالحالة `invalid` ولا يتيح شيئاً.

| الحالة          | المعنى                                                                           | الكتابة بالميزات المدفوعة |
| --------------- | -------------------------------------------------------------------------------- | ------------------------- |
| `valid`         | الترخيص سارٍ؛ تظهر `refreshFailing` عندما لا يجيب المركز لفترة                    | بوضع الوحدة               |
| `offline-grace` | لم يحدث تجديد منذ أكثر من يوم؛ يظل الرمز سارياً حتى `offlineGraceUntil`           | بوضع الوحدة               |
| `grace`         | انتهت مدة الترخيص؛ مهلة التجديد مستمرة حتى `graceUntil`                          | بوضع الوحدة               |
| `mismatch`      | يخص الرمز تثبيتاً آخر (استعادة في مكان آخر)؛ تستمر المهلة حتى `graceUntil`        | بوضع الوحدة حتى ذلك الوقت |
| `expired`       | ‏`trial_expired` أو `licence_expired` أو `activation_stale` (انتهت صلاحية الرمز) | بصيغة النواة              |
| `revoked`       | إبطال موقّع؛ يُعرض السبب                                                           | بصيغة النواة              |
| `invalid`       | يفشل التحقق من مستند مخزّن                                                        | بصيغة النواة              |

في كل الحالات، تبقى بياناتك قابلة للقراءة، وتعمل النسخ الاحتياطية والاستعادة، ولا يفشل النشر أبداً بسبب ترخيص: من دون ترخيص، تكتب الوحدة المدفوعة البيانات الجديدة بصيغة النواة المجانية. تُستأنف الكتابة بوضع الوحدة تلقائياً بعد تجديد ناجح.

## التجديد وفترة العمل دون اتصال {#refresh}

يجدد العامل كل تفعيل نحو مرة يومياً وعند بدء تشغيله. يجلب كل تجديد رمزاً جديداً وسراً جديداً؛ ويتوقف السر السابق عن العمل.

عندما يتعذر الوصول إلى المركز، يحاول العامل مجدداً بعد 15 دقيقة، ثم يطيل الانتظار كل مرة حتى 6 ساعات. يبقى الترخيص بالحالة `valid`؛ وبعد يوم دون تجديد يصبح `offline-grace`؛ وعندما تنتهي صلاحية الرمز (فترة العمل دون اتصال: 30 يوماً افتراضياً، و7 للنسخة التجريبية) يصبح `expired` مع `activation_stale`. لا تُعاد محاولة رفض صادر من المركز، مثل `licence_expired` أو `activation_suspended`: عالج سببه ثم نفّذ:

```bash
sudo arkvory license refresh --root /opt/proanima-arkvory
```

لا يمدد إرجاع الساعة إلى الوراء أي مدة: يعتمد Arkvory على أحدث وقت رآه. إذا تأخرت ساعة قاعدة البيانات عن ذلك الوقت بأكثر من يوم، تظهر `clockRollback`.

إذا كان التجديد قد وصل إلى المركز لكن استجابته فُقدت، يسمح Arkvory بإعادة إرسال واحدة فقط خلال فترة الـ10 دقائق، بما في ذلك بعد إعادة التشغيل. إذا بقيت النتيجة مجهولة، أو استُهلكت المحاولة المسموحة، أو انتهت الفترة، أو كان الرمز المُعاد غير صالح، يوقف `activation_recovery_required` أي تجديدات أخرى. يبقى الرمز الحالي صالحاً حتى انتهاء صلاحيته. استرجع المفتاح وكرر `license activate --key-file <file>`؛ لا يستطيع `license refresh` معالجة هذه الحالة.

### النسخ والاستعادة {#copies}

تحتفظ نسخة من التثبيت، مثل جهاز افتراضي مستنسخ، بالسر نفسه. عندما تجدد النسختان، يعلّق المركز التفعيل (`activation_secret_reused`). فعّل مجدداً بالمفتاح على التثبيت الذي ستحتفظ به.

تحتفظ النسخة الاحتياطية المستعادة على تثبيت آخر برمزها الذي يخص التثبيت القديم: تكون الحالة `mismatch` مع مهلة. فعّل التثبيت الجديد بالمفتاح، ثم ألغِ تفعيل القديم.

يسقط التفعيل الذي لم يُجدد طوال فترة عمله دون اتصال و30 يوماً إضافياً، ويتحرر موضعه. يستعيد التجديد التالي الموضع إذا توفر موضع حر؛ وإلا يُرفض بالرمز `activation_lapsed`. ألغِ تفعيل تثبيت آخر، ثم جدّد.

## إلغاء التفعيل {#deactivate}

```bash
sudo arkvory license deactivate lic_0123456789ABCDEFGHJKMNPQRS --root /opt/proanima-arkvory
```

حدد الترخيص أو تفعيلاً واحداً. يحرر المركز الموضع، ويحذف Arkvory السر.

## التفعيل دون اتصال {#offline}

للمضيفين الذين لا يستطيعون الوصول إلى المركز:

1. اكتب ملف طلب:

   ```bash
   sudo arkvory license request --key-file /root/arkvory.key --out /root/request.json --root /opt/proanima-arkvory
   ```

   يحتوي الملف على SHA-256 للمفتاح، وليس المفتاح أبداً. لا يستخدم Arkvory أي شبكة لإنشائه.

2. ارفع الملف في حساب ProAnimaStudio الخاص بك ونزّل الاستجابة.
3. ثبّت الاستجابة:

   ```bash
   sudo arkvory license install /root/answer.json --root /opt/proanima-arkvory
   ```

يجب أن تخص الاستجابة طلباً من هذا التثبيت. لا يُجدد التفعيل دون اتصال: يظل سارياً حتى نهايته، بحد أقصى 365 يوماً، ويجدده طلب جديد. لا يصل الإبطال إلى مضيف كهذا إلا بقائمة إبطال تراخيص تثبّتها بالطريقة نفسها.

## الأخطاء {#errors}

| الرمز                                               | المعنى                                                                          |
| --------------------------------------------------- | ------------------------------------------------------------------------------- |
| `licence_key_invalid`                               | لا يعرف المركز المفتاح                                                          |
| `activation_limit_reached`                          | جميع مواضع الترخيص مشغولة؛ ألغِ تفعيل تثبيت آخر                                  |
| `answer_invalid`                                    | الاستجابة غير موقّعة من ProAnimaStudio، أو تخص تثبيتاً أو طلباً آخر؛ لا يُحتفظ بشيء |
| `installation_mismatch` و`nonce_unknown`            | تخص الاستجابة دون اتصال تثبيتاً آخر، أو لا تخص أي طلب منتظر                      |
| `seq_replayed`                                      | مستند أقدم من المستند المحفوظ؛ يُرفض                                             |
| `revocation_rollback`                               | قائمة إبطال أقدم من القائمة المحفوظة                                            |
| `unreachable` و`timeout` و`tls_failed` و`hub_error` | تعذر الوصول إلى المركز؛ يعيد العامل المحاولة                                    |
