# اختيار طريقة التثبيت

يعمل Arkvory على خادم واحد. ولكل تثبيت الأجزاء نفسها:

- **API**: واجهة HTTP API ووحدة التحكم على الويب.
- **العامل (worker)**: ينهي عمليات الرفع وينفّذ مهام الخلفية.
- **وكيل النسخ الاحتياطي**: ينشئ نسخًا احتياطية مجدولة في مخزن النسخ الاحتياطية.
- **PostgreSQL**: قاعدة بيانات الفهرس.

يُخزَّن محتوى الملفات على قرص محلي في الخادم. وهذا الإعداد ليس نظام توافر عالٍ. يسبب التحديث أو تعطل الخادم انقطاعًا قصيرًا، ويستأنف العملاء عمليات النقل.

تثبّت كل الخيارات API والعامل ووكيل النسخ الاحتياطي نفسها. ويتوفر HTTPS المضمَّن للتثبيتات الأصلية فقط. أما تثبيت Compose فيحتاج إلى وكيل عكسي (reverse proxy) لتوفير HTTPS. راجع [HTTPS والوكيل العكسي](./https).

### التثبيت عن بُعد عبر SSH {#remote-installation-over-ssh}

**Arkvory Remote Setup** جزء من حزم العميل. يعمل على حاسوب المسؤول، ويتصل بخادم عبر SSH، ويثبّت هناك حزمة Linux أو Windows الأصلية. ثم ينشئ حساب المالك ويفتح وحدة التحكم عبر نفق SSH خاص.

| الخادم      | المتطلبات                                                                                    |
| ----------- | -------------------------------------------------------------------------------------------- |
| Linux x64   | SSH وSFTP، وsystemd، و`apt-get` أو `dnf`، وroot أو مستخدم يملك `sudo -n` (دون طلب كلمة مرور) |
| Windows x64 | OpenSSH Server مع SFTP، وWindows PowerShell، وحساب مسؤول                                     |

لا يعمل النفق إلا أثناء تشغيل Remote Setup، ولا ينشر Arkvory لحواسيب أخرى. ولا يُدعم `sudo` المحمي بكلمة مرور، ولا وكلاء SSH (SSH agents)، ولا مضيفات القفز (jump hosts)، ولا خوادم ARM.

## المتطلبات {#requirements}

| العنصر                          | المتطلب                                                                                                           |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Windows، برنامج التثبيت الرسومي | x64، إصدار Windows 10.0.17763 أو أحدث (Windows 10 الإصدار 1809، Windows Server 2019). صلاحيات المسؤول             |
| Windows، النص البرمجي           | x64، وWindows PowerShell. صلاحيات المسؤول للخدمات الأصلية                                                         |
| حزم Linux                       | x64، وsystemd، وglibc 2.28 أو أحدث، وPython 3. يثبّت مدير الحزم PostgreSQL 16 أو أحدث                             |
| Linux، النص البرمجي             | x64 أو arm64، وsystemd للخدمات الأصلية، وglibc، وBash، وcurl، وPython 3، وtar، وxz                                |
| Docker Compose                  | Docker Engine مع إضافة Compose، أو Docker Desktop بوضع حاويات Linux. ويمكن استخدام Podman مع موفّر compose متوافق |
| PostgreSQL                      | قاعدة بيانات واحدة لتثبيت Arkvory واحد. لا تربط تثبيتين بقاعدة البيانات نفسها أبدًا                               |
| تخزين الملفات                   | نظام ملفات محلي يدعم الروابط الصلبة (hard links). لا تستخدم مشاركة شبكية لتخزين الملفات                           |
| مخزن النسخ الاحتياطية           | وحدة تخزين منفصلة، مُحمَّلة (mounted) قبل بدء الخدمات. راجع [النسخ الاحتياطية](../operate/backups)                |

لا يحدد Arkvory حدودًا دنيا ثابتة للمعالج أو الذاكرة. خطّط لمساحة القرص لملفاتك وقاعدة البيانات ومخزن النسخ الاحتياطية. يُبقي Arkvory افتراضيًا 1 GiB من المساحة الحرة على وحدة التخزين، ويقبل حتى 10 TiB من عمليات الرفع المحجوزة. ويمكنك تغيير الحدين كليهما. راجع [الإعداد](./configuration).

### الوصول إلى الشبكة أثناء التثبيت والتحديث {#network-access-during-installation-and-updates}

يعمل برنامج التثبيت الرسومي دون إنترنت. أما الخيارات الأخرى فتنزّل ملفات عبر HTTPS:

| المضيف                                                   | يستخدمه                                                                                       |
| -------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| `nodejs.org`                                             | ينزّل كل من `install.sh` و`install.ps1` الإصدار 24.21.0 من Node.js ويتحقق من SHA-256 الخاص به |
| `api.github.com` و`github.com` ومضيفات التنزيل في GitHub | برامج التثبيت النصية، والتحديثات عندما يتعذر الوصول إلى مركز التحديثات                        |
| `hub.proanima.net`                                       | التحقق من التحديثات وتنزيلها. راجع [التحديثات](./updates)                                     |
| Docker Hub                                               | يبني Compose صورته من `node:24.21.0-bookworm-slim` ويشغّل `postgres:18.4`                     |

دون إنترنت، ثبّت وحدّث من نسخة محلية من الإصدار. راجع [التحديثات](./updates).

## المنافذ {#ports}

| المنفذ    | الخدمة                                                  | الإتاحة الافتراضية                                                                                                        |
| --------- | ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| 8080/TCP  | API ووحدة التحكم (HTTP، أو HTTPS مع TLS المضمَّن)       | `127.0.0.1` فقط. يمكن للتثبيت الأصلي أن يستمع إلى عناوين أخرى بعد إعداد HTTPS. وينشره Compose دائمًا على `127.0.0.1:8080` |
| 54329/TCP | PostgreSQL المُدار في برنامج التثبيت الرسومي وحزم Linux | `127.0.0.1` فقط                                                                                                           |
| 5432/TCP  | حاوية PostgreSQL في تثبيت Compose                       | غير منشور. لا يمكن الوصول إليه إلا داخل شبكة Compose                                                                      |

افتح منفذ HTTPS فقط لشبكات العملاء. ولا تفتح منفذ قاعدة البيانات أبدًا.

## دليل التثبيت {#installation-directory}

جذر التثبيت هو `C:\ProgramData\ProAnima\Arkvory` على Windows و`/opt/proanima-arkvory` على Linux. استخدم دليلًا مخصصًا فارغًا خارج الأدلة الرئيسية للمستخدمين (home) وملفاتهم الشخصية.

| المسار في الجذر                  | المحتوى                                                                    |
| -------------------------------- | -------------------------------------------------------------------------- |
| `installation.json`              | الإصدار المثبَّت ووضع التثبيت وإعداد التحديث التلقائي وتثبيت الإصدار (pin) |
| `journal.json` و`operation.lock` | حالة آخر تحديث، وقفل العملية الجارية                                       |
| `launcher.mjs` و`manage.mjs`     | يشغّلان الخدمات وأوامر الإدارة                                             |
| `releases/<version>/`            | شيفرة البرنامج لكل إصدار مثبَّت. لا تكتب الخدمات هنا                       |
| `runtime/`                       | Node.js. ويضع برنامج التثبيت الرسومي هنا أيضًا PostgreSQL وWinSW           |
| `config/`                        | الإعدادات والمفاتيح ومفتاح الاسترداد. راجع [الإعداد](./configuration)      |
| `data/`                          | تخزين الملفات في التثبيت الأصلي                                            |
| `database/`                      | عنقود PostgreSQL المُدار. وعلى Windows سجلاته أيضًا                        |
| `logs/`                          | سجلات خدمات Windows وسجل برنامج التحديث في Windows                         |
| `service/`                       | أغلفة خدمات Windows                                                        |
| `updates/`                       | طلبات التحديث من وحدة التحكم وحالة برنامج التحديث                          |

يحتفظ تثبيت Compose ببياناته في مجلدات Docker (volumes) باسم `proanima-arkvory_storage` (الملفات) و`proanima-arkvory_catalog` (قاعدة البيانات)، لا في `data/`.

لا تُحذف الإصدارات القديمة في `releases/` تلقائيًا. وبعد تحديث ناجح يمكنك حذف الإصدارات غير المستخدمة. احتفظ بالإصدار الحالي وبالإصدار السابق المذكور في `journal.json`.

## مفتاح الاسترداد {#recovery-key}

ينشئ برنامج التثبيت الملف `config/bootstrap-token.txt`. يحتوي هذا الملف على **مفتاح الاسترداد**: مفتاح بصلاحيات المسؤول. ولا يستطيع قراءته إلا root أو مجموعة Administrators.

- استخدمه مرة واحدة لإنشاء حساب المالك الأول إذا لم ينشئه برنامج التثبيت. وتطلبه وحدة التحكم عند أول تشغيل.
- تقرؤه أدوات التثبيت على الخادم: إنشاء المالك، و`arkvory configure --backup-vault`، والتحقق من النسخة الاحتياطية بعد التحديث، والنسخة الاحتياطية قبل تغيير مخطط قاعدة البيانات. **لا تحذف هذا الملف.**
- لا تنسخه إلى العملاء أو أنظمة CI أو النصوص البرمجية. وللعمل اليومي، أنشئ حسابات مستخدمين ومفاتيح خدمة بأذونات محدودة. راجع [الحسابات والوصول](../use/accounts).

لاستبدال مفتاح الاسترداد، راجع [الإعداد](./configuration).

## الخطوات التالية {#next-steps}

1. ثبّت باستخدام الصفحة الخاصة بمنصتك: [Windows](./windows) أو [Linux](./linux) أو [Docker Compose](./docker).
2. سجّل الدخول وانشر أول ملف. راجع [البدء السريع](../guide/quick-start).
3. اضبط [HTTPS](./https) قبل أن يتصل العملاء من حواسيب أخرى.
4. اربط مخزن نسخ احتياطية وشغّل أول نسخة احتياطية. راجع [النسخ الاحتياطية](../operate/backups).
5. اختر [سياسة التحديث](./updates).
