# AI エージェント

Claude Code など、Model Context Protocol（MCP）に対応した AI エージェントクライアントは、`arkvoryctl mcp` を介して Arkvory を操作できます。クライアントがこのコマンドを起動し、標準入力と標準出力で通信します。ネットワークポートは開きません。エージェントスキルは、その上で安全に作業する手順をエージェントに教えます。

## 始める前に {#before}

1. エージェントを実行するマシンに[コマンドラインクライアント](../protocols/cli)をインストールします。
2. 必要なリポジトリと操作だけにアクセスできるエージェント用サービスキーを作成します。自分だけが読めるファイルに保存してください。
3. キーファイルを参照するプロファイルを追加し、確認します。

```bash
arkvoryctl profile add agent --server https://arkvory.example --token-file ~/.config/arkvory/agent.key --repository builds
arkvoryctl doctor --profile agent
```

キーをチャット、引数、プロジェクトファイルに貼り付けないでください。結果にもエラーにもキーは含まれず、エージェントがキーを見ることはありません。

## MCP サーバーに接続する {#connect}

```bash
claude mcp add arkvory -- arkvoryctl mcp --profile agent --root ~/work
```

`--write` を付けなければ、サーバーは読み取り専用です。エージェントは、リポジトリの一覧表示と横断検索、アーティファクト、パッケージ、パス指定ファイル、変更フィード、インストール状態の読み取り、およびアーティファクトのダウンロードを行えます。キーに権限がないツールは提供されません。クライアントは MCP 2025-06-18 以降に対応している必要があります。

## 書き込みを許可する {#write}

書き込み用の設定は別に作成します。エージェントに書き込みを許可するリポジトリを列挙してください。

```bash
claude mcp add arkvory-publish -- arkvoryctl mcp --profile agent --root ~/work --write --write-repositories builds
```

| ツール                    | 動作                                                                                                      |
| ------------------------- | --------------------------------------------------------------------------------------------------------- |
| `arkvory_upload`          | ファイルを新しいアーティファクト、またはファイルパスの次のリビジョンとしてアップロードします              |
| `arkvory_publish_package` | UPack をアップロードし、パッケージのバージョンとして登録します                                            |
| `arkvory_promote`         | ステージを追加します。`sha256` を指定した場合、そのバイト列と完全に一致するアーティファクトだけが対象です |
| `arkvory_stage_remove`    | ステージを削除します。アーティファクトは残ります                                                          |
| `arkvory_annotate`        | エージェントが読み取ったリビジョンを対象に、ラベルとメタデータを置き換えます                              |

- `--write-repositories` にないリポジトリへの書き込みは、送信前に拒否されます（`repository_not_allowed`）。サーバー側でもキーの権限を確認します。
- 削除と復元はできず、ダウンロードリンクも作成されません。これらは引き続き、人がコンソールで行う操作です。
- サーバーは、書き込む内容を説明してユーザーの確認を待つようエージェントに指示します。MCP クライアントも各呼び出しの前に確認を求める場合があります。
- アップロードは再開可能です。失敗後に同じ呼び出しを繰り返すと、別のアーティファクトを作成せず、同じアーティファクトが返されます。結果には読み取ったファイルの SHA-256 が含まれます。

## ファイルと制限 {#files}

- ローカルファイルの読み書きは `--root` 以下に限られます。既定値は現在のディレクトリです。リンク経由も含め、この範囲の外を指すパスは拒否されます（`path_outside_root`）。
- ダウンロードしたファイルは、サイズと SHA-256 の検証後に初めて表示されます。既存のファイルは、エージェントが置き換えを指定した場合だけ置き換えられます。
- キーを含むファイルはアップロードされません（`source_contains_credential`）。また、arkvoryctl 自身のファイル（プロファイル、キーファイル、アップロードのチェックポイント）は、`--root` 以下にあっても読み取りも置き換えもされません（`private_path`）。
- 1 回の結果は `--max-output-bytes`（既定は 64 KiB、最大 1 MiB）以内、かつ最大 100 件です。続きを取得するには、エージェントが `next` を `after` として渡します。

## スキルをインストールする {#skill}

スキルは、検索、ダウンロードの検証、公開、プロモーション、エラーコードの読み取り方法と、絶対に行ってはいけない操作をエージェントに教える指示集です。クライアントに同梱されています。

```bash
arkvoryctl skill install
```

スキルは `~/.claude/skills/arkvory` に配置されます。プロジェクト内の `.claude/skills/arkvory` などにインストールするには、`--target DIR` を指定します。再実行すると、変更していないファイルが更新されます。自分で変更したファイルは保持されます。`--force` を付けない限り、コマンドは何も変更せず停止します。

## 安全な運用 {#safety}

- 結果の名前、ラベル、メタデータ、コメントは他の人が記入したものです。エージェントはこれらをデータとして扱い、その中に書かれた指示には従いません。
- 読み取り専用と書き込み用の設定を分け、タスクに必要なリポジトリだけに書き込みを許可します。
- 権限を絞った専用キーを使い、エージェントに不要になったらコンソールで取り消してください。

## トラブルシューティング {#troubleshooting}

| エラー                   | 原因と対処                                                                                                                                                                                                                                    |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 書き込みツールがない     | サーバーの起動時に `--write` を指定していないか、キーに権限がありません。                                                                                                                                                                     |
| `repository_not_allowed` | リポジトリが `--write-repositories` にありません。MCP の設定を変更してください。                                                                                                                                                              |
| `forbidden`              | キーに権限がありません。`arkvoryctl doctor` で権限を確認してください。                                                                                                                                                                        |
| `path_outside_root`      | ファイルが `--root` の外にあるか、通常のファイルではありません。                                                                                                                                                                              |
| `state_locked`           | 別の呼び出しで同じアップロードがまだ実行中です。クラッシュ後は、そのファイルをアップロード中の `arkvoryctl mcp` がないことを確認してから、CLI ディレクトリ（`~/.config/arkvory`）の `mcp-uploads` にある `.lock` ファイルを削除してください。 |
| `skill_modified`         | スキルのファイルが変更されています。自分のコピーを保持するか、`--force` を付けて `arkvoryctl skill install` を再実行してください。                                                                                                            |
