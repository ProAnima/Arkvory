# 環境変数

Arkvoryは、名前が`ARKVORY_`で始まる環境変数で設定します。このページには、サーバーのプロセス、コマンドラインクライアント、インストーラースクリプトが読み取るすべての変数を載せています。

## 値の取得元 {#where-the-values-come-from}

インストーラーは、サーバーの設定を、インストールルートの`config/runtime.json`という1つのファイルに書き込みます。各サービスのランチャーがこのファイルを読み、その値をAPI、ワーカー、バックアップエージェントに渡します。各キーは`ARKVORY_`で始まる必要があり、各値は文字列である必要があります。

```json
{
  "ARKVORY_HOST": "127.0.0.1",
  "ARKVORY_PORT": "8080",
  "ARKVORY_CAPACITY_BYTES": "10995116277760",
  "ARKVORY_DATABASE_URL": "postgresql://arkvory:PASSWORD@127.0.0.1:54329/arkvory",
  "ARKVORY_DATA_DIR": "/opt/proanima-arkvory/data",
  "ARKVORY_KEYS_FILE": "/opt/proanima-arkvory/config/keys.json",
  "ARKVORY_MAX_DOWNLOADS": "32"
}
```

このファイルには、データベースのパスワードが含まれています。アクセス権は、インストーラーが設定したままにしてください。

設定を変更するには、`config/runtime.json`を編集して、サービスを再起動します。`arkvory configure`コマンドがその設定に対応している場合（HTTPS、バックアップの保管庫、ミラー、更新）は、そちらを優先してください。このコマンドは変更を検証し、サービスが起動しない場合は元のファイルに戻します。[設定](../install/configuration)を参照してください。

```bash
sudo systemctl restart arkvory-api arkvory-worker arkvory-backup
```

```powershell
Restart-Service Arkvoryapi, Arkvoryworker, Arkvorybackup
```

許容範囲外の値があると、プロセスは起動時に、変数名を示すメッセージとともに停止します。その場合、Arkvoryが既定値にフォールバックすることはありません。

「読み取るプロセス」の列では、次の名前を使います。**API**はHTTPサーバー（読み取りゲートウェイも含む）、**ワーカー**はバックグラウンドのワーカー、**エージェント**はバックアップエージェント、**CLI**は`arkvoryctl`です。

## 基本設定 {#core}

| 変数                         | 読み取るプロセス                              | 既定値            | 意味                                                                                                                                                             |
| ---------------------------- | --------------------------------------------- | ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ARKVORY_DATABASE_URL`       | API、ワーカー、エージェント、マイグレーション | 必須              | PostgreSQLの接続URL（`postgres://`または`postgresql://`）。インストールごとに、別々のデータベースを使ってください。                                              |
| `ARKVORY_DATA_DIR`           | API、ワーカー、エージェント                   | 必須              | ローカルのストレージディレクトリ。ステージング、コンテンツ、`storage-id`ファイルが入ります。ネットワーク共有は使用しないでください。                             |
| `ARKVORY_HOST`               | API                                           | `127.0.0.1`       | 待ち受けるアドレス。インストーラーは`127.0.0.1`を書き込みます。Docker Composeではコンテナー内で`0.0.0.0`になり、ポートはホストのループバックでのみ公開されます。 |
| `ARKVORY_PORT`               | API                                           | `8080`            | TCPポート。1〜65535。                                                                                                                                            |
| `ARKVORY_WEB_DIR`            | API                                           | `apps/web/public` | Webコンソールのファイルがあるディレクトリ。ランチャーが、起動のたびに現在のリリースを指すように設定します。                                                      |
| `ARKVORY_DATABASE_POOL_SIZE` | API                                           | `10`              | APIの接続プールのサイズ。4〜200。3つまでの接続は、常に使用中です。                                                                                               |

## ストレージと制限 {#storage-and-limits}

| 変数                            | 読み取るプロセス            | 既定値       | 意味                                                                                                                                                                                                 |
| ------------------------------- | --------------------------- | ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ARKVORY_CAPACITY_BYTES`        | API、ワーカー               | 10 TiB       | 予約済みのすべてのコンテンツ（公開済み、未完了のアップロード、クリーンアップを待つコンテンツ）の上限（バイト）。ディスクの確認ではありません。ワーカーが読み取るのは、ミラーのコピーのときだけです。 |
| `ARKVORY_STORAGE_RESERVE_BYTES` | API、ワーカー、エージェント | `1073741824` | アップロードが使用しない空き容量（バイト）。データベース、ログ、システム用に確保されます。`0`にすると、この確保をオフにします。                                                                      |
| `ARKVORY_MAX_OBJECT_BYTES`      | API                         | 約10 TiB     | 最大のオブジェクトのサイズ（バイト）。設定できる最大値は、1 GiBのパート10,000個分です。ファイルサイズを制限するには、これより小さい値を設定します。                                                  |

## 転送と帯域 {#transfers-and-bandwidth}

これらの制限は、1つのAPIプロセスごとに適用されます。速度の単位は、1秒あたりのバイト数です。`0`は無制限を意味し、それ以外の値は65,536〜1 TiBの範囲にする必要があります。

| 変数                                              | 読み取るプロセス | 既定値    | 意味                                                                                                                                                                                              |
| ------------------------------------------------- | ---------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ARKVORY_MAX_UPLOADS`                             | API              | `2`       | 同時に実行されるアップロードの数。1〜32。                                                                                                                                                         |
| `ARKVORY_MAX_DOWNLOADS`                           | API              | `16`      | 同時に実行されるダウンロードの数。1〜256。                                                                                                                                                        |
| `ARKVORY_MAX_UPLOADS_PER_PRINCIPAL`               | API              | `1`       | 1つのアカウントまたはキーが同時に実行できるアップロードの数。アップロード全体の上限以下。                                                                                                         |
| `ARKVORY_MAX_DOWNLOADS_PER_PRINCIPAL`             | API              | `4`       | 1つのアカウントまたはキーが同時に実行できるダウンロードの数。ダウンロード全体の上限以下。                                                                                                         |
| `ARKVORY_TRANSFER_QUEUE_LIMIT`                    | API              | `64`      | 空きスロットを待てる転送の数。1〜1024。                                                                                                                                                           |
| `ARKVORY_TRANSFER_QUEUE_PER_PRINCIPAL`            | API              | `8`       | 1つのアカウントまたはキーの、待機中の転送の数。キューの上限以下。                                                                                                                                 |
| `ARKVORY_TRANSFER_QUEUE_TIMEOUT_MS`               | API              | `20000`   | 転送がキューで待てる時間。1〜120,000 ms。                                                                                                                                                         |
| `ARKVORY_MAX_REQUESTS`                            | API              | `128`     | 同時に処理する認証済みリクエストの数。1〜4096。アップロード数とダウンロード数の合計より大きい必要があります。未設定で、転送の上限が大きい場合の既定値は、アップロード数＋ダウンロード数＋64です。 |
| `ARKVORY_UPLOAD_BYTES_PER_SECOND`                 | API              | `0`       | プロセス全体のアップロード速度。                                                                                                                                                                  |
| `ARKVORY_DOWNLOAD_BYTES_PER_SECOND`               | API              | `0`       | プロセス全体のダウンロード速度。                                                                                                                                                                  |
| `ARKVORY_UPLOAD_BYTES_PER_SECOND_PER_PRINCIPAL`   | API              | `0`       | 1つのアカウントまたはキーのアップロード速度。そのすべての接続の合計。                                                                                                                             |
| `ARKVORY_DOWNLOAD_BYTES_PER_SECOND_PER_PRINCIPAL` | API              | `0`       | 1つのアカウントまたはキーのダウンロード速度。そのすべての接続の合計。                                                                                                                             |
| `ARKVORY_UPLOAD_IDLE_TIMEOUT_MS`                  | API              | `30000`   | この時間データを送らないアップロードリクエストは、停止されます。1〜1,800,000 ms。                                                                                                                 |
| `ARKVORY_UPLOAD_DEADLINE_MS`                      | API              | `1800000` | 1回のアップロードリクエストの最長時間。1〜1,800,000 ms。アイドルタイムアウトより短くはできません。                                                                                                |

## ネットワーク、HTTPS、ブラウザー {#network-https-and-browsers}

| 変数                         | 読み取るプロセス | 既定値    | 意味                                                                                                                              |
| ---------------------------- | ---------------- | --------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `ARKVORY_TLS_CERT_FILE`      | API              | 未設定    | 内蔵HTTPS用のPEM証明書（チェーンを含む）。キーファイルと一緒に設定します。                                                        |
| `ARKVORY_TLS_KEY_FILE`       | API              | 未設定    | パスワードなしのPEM秘密鍵。                                                                                                       |
| `ARKVORY_TLS_MIN_VERSION`    | API              | `TLSv1.2` | `TLSv1.2`または`TLSv1.3`。                                                                                                        |
| `ARKVORY_TLS_RELOAD_SECONDS` | API              | `300`     | 更新された証明書ファイルを読み直す間隔。30〜86,400秒。`0`にすると、起動時にだけ読み取ります。                                     |
| `ARKVORY_CORS_ORIGINS`       | API              | 空        | 別のアドレスにあるコンソール用の、ブラウザーのオリジンのカンマ区切りのリスト（最大16個）。HTTPS、またはループバックのHTTPのみ。   |
| `ARKVORY_TRUSTED_PROXIES`    | API              | 空        | リバースプロキシのアドレス（IPまたはCIDR）を最大32個。`X-Forwarded-For`でクライアントのアドレスを設定できるのは、これらだけです。 |

内蔵のHTTPSは、ネイティブインストール向けです。Docker Composeでは、リバースプロキシを使います。[HTTPS](../install/https)を参照してください。

## IDとキー {#identity-and-keys}

| 変数                         | 読み取るプロセス | 既定値 | 意味                                                                                                                                      |
| ---------------------------- | ---------------- | ------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `ARKVORY_KEYS_FILE`          | API、ワーカー    | 必須   | 回復キーやヘルスチェック用キーなどの、ファイルキーを記述したJSONファイル。保存するのはSHA-256ハッシュであり、キーそのものではありません。 |
| `ARKVORY_ALLOW_REGISTRATION` | API              | オフ   | `true`にすると、サインインページで利用者が自分のアカウントを作成できます。それ以外の値では、オフのままです。                              |

## バックアップ {#backups}

| 変数                              | 読み取るプロセス | 既定値   | 意味                                                                                                                                                           |
| --------------------------------- | ---------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ARKVORY_BACKUP_VAULT`            | エージェント     | 未設定   | 初期化済みの保管庫のディレクトリ。未設定の場合、エージェントは動作し、保管庫が設定されていないと報告します。`arkvory configure --backup-vault`が書き込みます。 |
| `ARKVORY_BACKUP_BYTES_PER_SECOND` | エージェント     | 制限なし | バックアップのコピー速度の上限。65,536以上。                                                                                                                   |
| `ARKVORY_BACKUP_POLL_SECONDS`     | エージェント     | `15`     | エージェントが新しいバックアップジョブを確認する間隔。1〜3600秒。                                                                                              |
| `ARKVORY_BACKUP_LEASE_SECONDS`    | エージェント     | `60`     | 2つ目のエージェントが同時に実行されるのを防ぐための、リースの時間。2〜3600秒。                                                                                 |
| `ARKVORY_BACKUP_SNAPSHOT_SECONDS` | エージェント     | `1800`   | バックアップのうち、データベースのスナップショット部分の制限時間。60〜86,400秒。                                                                               |
| `ARKVORY_BACKUP_BARRIER_SECONDS`  | エージェント     | `30`     | 実行中のクリーンアップのステップを、バックアップが待つ時間。1〜600秒。                                                                                         |
| `ARKVORY_RESTORE_DATABASE_URL`    | 復元コマンド     | 未設定   | 復元先のデータベース。他のユーザーがプロセス一覧で見られないため、`--database-url`より安全です。                                                               |

[バックアップ](../operate/backups)を参照してください。

## ミラー {#mirrors}

| 変数                      | 読み取るプロセス | 既定値 | 意味                                                                                                   |
| ------------------------- | ---------------- | ------ | ------------------------------------------------------------------------------------------------------ |
| `ARKVORY_MIRRORS_FILE`    | API、ワーカー    | 未設定 | ミラー対象のリポジトリを一覧するJSONファイル（最大64個）。`arkvory configure --mirror`が書き込みます。 |
| `ARKVORY_MIRRORS_CA_FILE` | ワーカー         | 未設定 | ソースのサーバー用に、追加の認証局を含むPEMファイルへの絶対パス。TLSは常に検証されます。               |

[ミラー](../operate/mirrors)を参照してください。

## Webhook {#webhooks}

| 変数                             | 読み取るプロセス | 既定値 | 意味                                                                                                                              |
| -------------------------------- | ---------------- | ------ | --------------------------------------------------------------------------------------------------------------------------------- |
| `ARKVORY_WEBHOOKS_FILE`          | ワーカー         | 未設定 | Webhook サブスクリプションを列挙する JSON ファイル（最大 16 件）。ない場合は Webhook は送信されません。                           |
| `ARKVORY_WEBHOOKS_ALLOW_PRIVATE` | ワーカー         | 未設定 | 公開アドレスに加えて Webhook を受信できるネットワークを、カンマ区切りの CIDR 形式で指定します（最大 32 件）。例: `10.20.0.0/16`。 |
| `ARKVORY_WEBHOOKS_CA_FILE`       | ワーカー         | 未設定 | 受信側向けの追加の認証局を含む PEM ファイルの絶対パス。TLS は常に検証されます。                                                   |

参照: [Webhook](../protocols/webhooks)。

## 更新とハブ {#updates-and-the-hub}

| 変数                         | 読み取るプロセス | 既定値                     | 意味                                                                                                                                                          |
| ---------------------------- | ---------------- | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ARKVORY_HUB_URL`            | API              | `https://hub.proanima.net` | ProAnimaStudioのハブのアドレス。コンソールのフィードバックで使われます。空の値にすると、フィードバックがオフになります。HTTPS、またはループバックのHTTPのみ。 |
| `ARKVORY_HUB_PROJECT`        | API              | `arkvory`                  | ハブでのプロジェクト名。                                                                                                                                      |
| `ARKVORY_UPDATE_CONTROL_DIR` | API              | 未設定                     | APIがホストの更新ツールと共有するディレクトリ。インストーラーが設定します。未設定の場合、コンソールから更新をリクエストできません。                           |

[更新](../install/updates)を参照してください。

## ログとシャットダウン {#logging-and-shutdown}

| 変数                       | 読み取るプロセス            | 既定値  | 意味                                                                                 |
| -------------------------- | --------------------------- | ------- | ------------------------------------------------------------------------------------ |
| `ARKVORY_LOG_LEVEL`        | API、ワーカー、エージェント | `info`  | `debug`、`info`、`warning`、`error`のいずれか。                                      |
| `ARKVORY_ACCESS_LOG`       | API                         | `true`  | `true`にすると、HTTPリクエストごとにJSONを1行書き込みます。`false`でオフになります。 |
| `ARKVORY_DRAIN_TIMEOUT_MS` | API                         | `30000` | 停止シグナルの後、実行中のリクエストが完了するまでの時間。0〜3,600,000 ms。          |

## 読み取りゲートウェイ {#read-gateways}

これらの変数のいずれかを設定した場合は、スロット、スロットの数、共有する速度が必須になります。書き込み側は、ロール`api`とスロット`0`を使います。各読み取りゲートウェイは、ロール`reader`と、それぞれ固有のスロットを使います。[読み取りゲートウェイ](../operate/read-gateways)を参照してください。

| 変数                                                     | 読み取るプロセス | 既定値 | 意味                                                                                                      |
| -------------------------------------------------------- | ---------------- | ------ | --------------------------------------------------------------------------------------------------------- |
| `ARKVORY_ROLE`                                           | API              | `api`  | `api`（書き込み側）または`reader`（読み取りゲートウェイ）。                                               |
| `ARKVORY_GATEWAY_SLOTS`                                  | API              | 未設定 | ダウンロード速度の上限を共有するプロセスの数。2〜16。                                                     |
| `ARKVORY_GATEWAY_SLOT`                                   | API              | 未設定 | このプロセスのスロット。`0`から、スロットの数マイナス1まで。                                              |
| `ARKVORY_SHARED_DOWNLOAD_BYTES_PER_SECOND`               | API              | 未設定 | すべてのプロセスの合計ダウンロード速度。各スロットに均等に配分され、1秒あたり65,536バイト以上になります。 |
| `ARKVORY_SHARED_DOWNLOAD_BYTES_PER_SECOND_PER_PRINCIPAL` | API              | `0`    | 1つのアカウントまたはキーの、すべてのプロセスにわたる合計ダウンロード速度。`0`は制限なしを意味します。    |

## ウォッチドッグ {#watchdog}

| 変数                       | 読み取るプロセス            | 既定値 | 意味                                                                                                                                                              |
| -------------------------- | --------------------------- | ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ARKVORY_WATCHDOG_SECONDS` | API、ワーカー、エージェント | `60`   | この時間ブロックされたままのプロセスは、自分で終了し、サービスマネージャーが再起動します。`0`にするとオフになります（デバッガー用）。それ以外の場合は10〜3600秒。 |

[自己修復](../operate/self-healing)を参照してください。

## インストーラースクリプト {#installer-scripts}

これらの変数は、Linuxの`install.sh`が読み取ります。Windowsの`install.ps1`は、代わりに`-Root`や`-Artifact`などのパラメーターを使います。

| 変数                      | 既定値                  | 意味                                                                                                           |
| ------------------------- | ----------------------- | -------------------------------------------------------------------------------------------------------------- |
| `ARKVORY_INSTALL_ROOT`    | `/opt/proanima-arkvory` | インストールルート。ネイティブインストールを、ホームディレクトリに置かないでください。                         |
| `ARKVORY_ARTIFACT_DIR`    | 未設定                  | 展開済みのリリースのディレクトリ。スクリプトは、リリースをダウンロードする代わりに、これをインストールします。 |
| `ARKVORY_RELEASE_VERSION` | 最新の安定版            | インストールする安定版の正確なバージョン（`1.2.3`など）。                                                      |

## インストーラーが設定するもの {#set-by-the-installer}

インストーラーは、自身のヘルパープロセス用に、これらの変数を設定します。自分で設定しないでください。

| 変数                      | 意味                                                                                      |
| ------------------------- | ----------------------------------------------------------------------------------------- |
| `ARKVORY_IMAGE`           | 現在のリリースのコンテナーイメージ。`config/compose.env`にあります。                      |
| `ARKVORY_SERVICE_WRAPPER` | Windowsのバックアップサービスのラッパーへのパス。サービスが停止しているときに使われます。 |
| `ARKVORY_PROTECT_ROOT`    | Windowsでアクセスルールを設定する対象の、インストールルート。                             |
| `ARKVORY_ENGINE_USER`     | Docker Desktopを使うWindowsで、現在のユーザーにルートへのアクセスを与えます。             |
