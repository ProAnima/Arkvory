# Лицензии

Бесплатному ядру Arkvory лицензия не нужна. Все функции из этой документации работают без неё, и ни одно состояние лицензии не выключает их и не делает данные нечитаемыми. Лицензия включает платный модуль ProAnimaStudio (см. [Модули](modules)). Пока вы не активировали лицензию, Arkvory никуда не отправляет ничего о лицензиях.

Команды этой страницы выполняются на хосте установки: от root в Linux или от администратора в Windows. Установки Docker Compose не загружают модули, поэтому эти команды там отклоняются.

## Активация онлайн {#activate}

1. Сохраните ключ лицензии с сайта ProAnimaStudio в файл, который можете читать только вы, например `/root/arkvory.key`.
2. Активируйте:

   ```bash
   sudo arkvory license activate --key-file /root/arkvory.key --root /opt/proanima-arkvory
   ```

3. Удалите файл ключа. Arkvory не хранит ключ, и он больше не понадобится.

Arkvory отправляет запрос в хаб установки (адрес из `config/hub.json`, тот же, что для обновлений) по HTTPS с проверкой сертификата. Ответ принимается, только если его подписал ключ лицензий ProAnimaStudio — для этой установки и этого запроса. Ключ с опечаткой отклоняется до отправки. Повторная активация той же установки тем же ключом не занимает нового места лицензии.

### Что отправляется {#sent}

| Запрос     | Содержимое                                                                                                                |
| ---------- | ------------------------------------------------------------------------------------------------------------------------- |
| Активация  | Ключ лицензии, id установки, случайное значение, версия Arkvory, id и версии установленных платных модулей, время запроса |
| Обновление | Id активации и её секрет, случайное значение, порядковый номер, версии                                                    |

Название владельца лицензии, имена людей, адреса, сведения о машине, объёмы данных, имена репозиториев, содержимое, metadata и статистика использования не отправляются никогда. Выключенная статистика ничего здесь не добавляет и не убирает. При выключенном хабе (`--hub-off`) используйте [офлайн-активацию](#offline).

### Что хранится {#kept}

- Токен — подписанный документ хаба — в базе данных и в резервных копиях.
- Секрет активации — файл в `config/licenses/`, который читает только учётная запись служб. Его нет в базе данных, журналах и резервных копиях.
- Ключ лицензии — нигде.

## Проверка состояния {#status}

```bash
sudo arkvory license status --root /opt/proanima-arkvory
```

Для скриптов добавьте `--json`. Глобальный администратор видит то же в `GET /api/v1/system/license` ([справочник](../api/reference/system#getSystemLicense)). Arkvory каждый раз заново проверяет каждый сохранённый документ; документ без подписи ProAnimaStudio — `invalid` и ничего не включает.

| Состояние       | Значение                                                                                            | Платная запись               |
| --------------- | --------------------------------------------------------------------------------------------------- | ---------------------------- |
| `valid`         | Лицензия действует; `refreshFailing`, если хаб какое-то время не отвечает                           | в режиме модуля              |
| `offline-grace` | Обновления нет больше суток; токен действует до `offlineGraceUntil`                                 | в режиме модуля              |
| `grace`         | Срок лицензии кончился; льготный период продления до `graceUntil`                                   | в режиме модуля              |
| `mismatch`      | Токен принадлежит другой установке (восстановление в другом месте); льготный период до `graceUntil` | в режиме модуля до его конца |
| `expired`       | `trial_expired`, `licence_expired` или `activation_stale` (токен кончился)                          | в форме ядра                 |
| `revoked`       | Подписанный отзыв; причина показана                                                                 | в форме ядра                 |
| `invalid`       | Сохранённый документ не проходит проверку                                                           | в форме ядра                 |

В любом состоянии данные остаются читаемыми, резервное копирование и восстановление работают, а публикация никогда не отказывает из-за лицензии: без лицензии платный модуль пишет новые данные в форме бесплатного ядра. Запись в режиме модуля возобновляется сама после успешного обновления.

## Обновление и офлайн-окно {#refresh}

Worker обновляет каждую активацию примерно раз в сутки и при запуске. Каждое обновление приносит новый токен и новый секрет; прежний секрет перестаёт действовать.

Если хаб недоступен, worker повторяет попытку через 15 минут, затем каждый раз ждёт дольше, до 6 часов. Лицензия остаётся `valid`; через сутки без обновления она `offline-grace`; когда токен кончается (офлайн-окно: по умолчанию 30 дней, у пробного периода 7), она `expired` с `activation_stale`. Отказ хаба, например `licence_expired` или `activation_suspended`, не повторяется: устраните причину и выполните:

```bash
sudo arkvory license refresh --root /opt/proanima-arkvory
```

Перевод часов назад ничего не продлевает: Arkvory судит по самому позднему времени, которое видел. Если часы базы данных отстают от него больше чем на сутки, показывается `clockRollback`.

### Копии и восстановление {#copies}

Копия установки, например клон виртуальной машины, хранит тот же секрет. Когда обновляются обе копии, хаб приостанавливает активацию (`activation_secret_reused`). Активируйте заново ключом ту установку, которую оставляете.

Резервная копия, восстановленная на другой установке, сохраняет токен, который принадлежит прежней установке: состояние `mismatch` с льготным периодом. Активируйте новую установку ключом, затем деактивируйте прежнюю.

Активация, которая не обновлялась дольше своего офлайн-окна и ещё 30 дней, истекает, и её место освобождается. Следующее обновление занимает место снова, пока свободное есть; иначе оно отклоняется с `activation_lapsed`. Деактивируйте другую установку и обновите.

## Деактивация {#deactivate}

```bash
sudo arkvory license deactivate lic_0123456789ABCDEFGHJKMNPQRS --root /opt/proanima-arkvory
```

Укажите лицензию или одну активацию. Хаб освобождает место, а Arkvory удаляет секрет.

## Офлайн-активация {#offline}

Для хостов без доступа к хабу:

1. Создайте файл запроса:

   ```bash
   sudo arkvory license request --key-file /root/arkvory.key --out /root/request.json --root /opt/proanima-arkvory
   ```

   В файле SHA-256 ключа, а не сам ключ. Arkvory для этого не обращается к сети.

2. Загрузите файл в личном кабинете ProAnimaStudio и скачайте ответ.
3. Установите ответ:

   ```bash
   sudo arkvory license install /root/answer.json --root /opt/proanima-arkvory
   ```

Ответ должен относиться к запросу этой установки. Офлайн-активация не обновляется: она действует до своего конца, не больше 365 дней, и продлевается новым запросом. Отзыв доходит до такого хоста только со списком отзыва лицензий, который устанавливается так же.

## Ошибки {#errors}

| Код                                                 | Значение                                                                                             |
| --------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `licence_key_invalid`                               | Хаб не знает этот ключ                                                                               |
| `activation_limit_reached`                          | Все места лицензии заняты; деактивируйте другую установку                                            |
| `answer_invalid`                                    | Ответ не подписан ProAnimaStudio или относится к другой установке или запросу; ничего не сохраняется |
| `installation_mismatch`, `nonce_unknown`            | Офлайн-ответ относится к другой установке или ни к одному ожидающему запросу                         |
| `seq_replayed`                                      | Документ старше сохранённого; отклонён                                                               |
| `revocation_rollback`                               | Список отзыва старше сохранённого                                                                    |
| `unreachable`, `timeout`, `tls_failed`, `hub_error` | Хаб недоступен; worker повторит попытку                                                              |
