# Выбор установки

Arkvory работает на одном сервере. В любой установке одни и те же части:

- **API**: HTTP API и веб-консоль.
- **Обработчик (worker)**: завершает загрузки и выполняет фоновые задания.
- **Агент резервного копирования**: делает резервные копии по расписанию в хранилище копий.
- **PostgreSQL**: база данных каталога.

Содержимое файлов хранится на локальном диске сервера. Эта схема не обеспечивает высокой доступности. Обновление или отказ сервера вызывает короткий перерыв, после которого клиенты возобновляют передачи.

### Удалённая установка по SSH {#remote-installation-over-ssh}

**Arkvory Remote Setup** входит в клиентские пакеты. Программа запускается на компьютере администратора, подключается к серверу по SSH и устанавливает там нативный пакет для Linux или Windows. Затем она создаёт учётную запись владельца и открывает консоль через закрытый SSH-туннель.

| Сервер      | Требования                                                                                       |
| ----------- | ------------------------------------------------------------------------------------------------ |
| Linux x64   | SSH и SFTP, systemd, `apt-get` или `dnf`, root или пользователь с `sudo -n` (без запроса пароля) |
| Windows x64 | OpenSSH Server с SFTP, Windows PowerShell, учётная запись администратора                         |

Туннель работает, только пока выполняется Remote Setup. Он не открывает Arkvory другим компьютерам. `sudo` с паролем, SSH-агенты, промежуточные узлы (jump host) и серверы ARM не поддерживаются.

## Требования {#requirements}

| Компонент                       | Требование                                                                                                                        |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Windows, графический установщик | x64, Windows сборки 10.0.17763 или новее (Windows 10 версии 1809, Windows Server 2019). Права администратора                      |
| Windows, скрипт                 | x64, Windows PowerShell. Права администратора для нативных служб                                                                  |
| Пакеты для Linux                | x64, systemd, glibc 2.28 или новее, Python 3. Менеджер пакетов устанавливает PostgreSQL 16 или новее                              |
| Linux, скрипт                   | x64 или arm64, systemd для нативных служб, glibc, Bash, curl, Python 3, tar и xz                                                  |
| Docker Compose                  | Docker Engine с плагином Compose или Docker Desktop в режиме контейнеров Linux. Возможен Podman с совместимым провайдером compose |
| PostgreSQL                      | Одна база данных на одну установку Arkvory. Никогда не подключайте две установки к одной базе данных                              |
| Хранилище файлов                | Локальная файловая система с поддержкой жёстких ссылок. Не размещайте хранилище файлов в сетевой папке                            |
| Хранилище копий                 | Отдельный том, подключённый до запуска служб. См. [Резервные копии](../operate/backups)                                           |

Arkvory не задаёт фиксированных минимальных требований к процессору и памяти. Планируйте место на диске для ваших файлов, базы данных и хранилища копий. По умолчанию Arkvory оставляет свободным 1 ГиБ на томе хранилища и принимает до 10 ТиБ зарезервированных загрузок. Оба предела можно изменить. См. [Настройка](./configuration).

### Доступ к сети при установке и обновлении {#network-access-during-installation-and-updates}

Графический установщик работает без доступа в интернет. Остальные варианты скачивают файлы по HTTPS:

| Узел                                                    | Для чего                                                                                       |
| ------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| `nodejs.org`                                            | `install.sh` и `install.ps1` скачивают Node.js 24.21.0 и проверяют его SHA-256                 |
| `api.github.com`, `github.com` и узлы скачивания GitHub | Скриптовые установщики и обновления, когда хаб обновлений недоступен                           |
| `hub.proanima.net`                                      | Проверка и скачивание обновлений. См. [Обновления](./updates)                                  |
| Docker Hub                                              | Compose собирает свой образ на основе `node:24.21.0-bookworm-slim` и запускает `postgres:18.4` |

Без доступа в интернет устанавливайте и обновляйте Arkvory из локальной копии релиза. См. [Обновления](./updates).

## Порты {#ports}

| Порт      | Служба                                                              | Доступность по умолчанию                                                                                                                                                      |
| --------- | ------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 8080/TCP  | API и консоль (HTTP или HTTPS со встроенным TLS)                    | Только `127.0.0.1`. Нативная установка может слушать другие адреса после настройки HTTPS или за доверенным прокси-сервером. Compose всегда публикует порт на `127.0.0.1:8080` |
| 54329/TCP | Управляемый PostgreSQL графического установщика и пакетов для Linux | Только `127.0.0.1`                                                                                                                                                            |
| 5432/TCP  | Контейнер PostgreSQL установки Compose                              | Не публикуется. Доступен только внутри сети Compose                                                                                                                           |

Открывайте для клиентских сетей только порт HTTPS. Порт базы данных не открывайте никогда.

## Каталог установки {#installation-directory}

Корень установки — `C:\ProgramData\ProAnima\Arkvory` в Windows и `/opt/proanima-arkvory` в Linux. Используйте отдельный пустой каталог вне домашних каталогов и профилей пользователей.

| Путь в корне                     | Содержимое                                                                           |
| -------------------------------- | ------------------------------------------------------------------------------------ |
| `installation.json`              | Установленная версия, режим установки, настройка автообновления и закрепление версии |
| `journal.json`, `operation.lock` | Состояние последнего обновления и блокировка выполняющейся операции                  |
| `launcher.mjs`, `manage.mjs`     | Запуск служб и команды управления                                                    |
| `releases/<версия>/`             | Код программы каждой установленной версии. Службы сюда не пишут                      |
| `runtime/`                       | Node.js. Графический установщик также помещает сюда PostgreSQL и WinSW               |
| `config/`                        | Настройки, ключи и ключ восстановления. См. [Настройка](./configuration)             |
| `data/`                          | Хранилище файлов нативной установки                                                  |
| `database/`                      | Управляемый кластер PostgreSQL. В Windows здесь же его журналы                       |
| `logs/`                          | Журналы служб Windows и журнал средства обновления Windows                           |
| `service/`                       | Обёртки служб Windows                                                                |
| `updates/`                       | Запросы на обновление из консоли и состояние средства обновления                     |

Установка Compose хранит данные в томах Docker `proanima-arkvory_storage` (файлы) и `proanima-arkvory_catalog` (база данных), а не в `data/`.

Старые версии в `releases/` не удаляются автоматически. После успешного обновления неиспользуемые версии можно удалить. Оставьте текущую версию и предыдущую версию, указанную в `journal.json`.

## Ключ восстановления {#recovery-key}

Установщик создаёт файл `config/bootstrap-token.txt`. В нём хранится **ключ восстановления** — ключ с правами администратора. Прочитать его могут только root или группа «Администраторы».

- Используйте его один раз, чтобы создать первую учётную запись владельца, если установщик её не создал. При первом запуске консоль запрашивает этот ключ.
- Средства установки читают его на сервере: при создании владельца, в `arkvory configure --backup-vault`, при проверке резервной копии после обновления и при создании копии перед изменением схемы базы данных. **Не удаляйте этот файл.**
- Не копируйте его на клиентские машины, в системы CI или скрипты. Для повседневной работы создавайте учётные записи пользователей и ключи сервисов с ограниченными правами. См. [Учётные записи и доступ](../use/accounts).

Чтобы заменить ключ восстановления, см. [Настройка](./configuration).

## Дальнейшие шаги {#next-steps}

1. Установите Arkvory по странице для вашей платформы: [Windows](./windows), [Linux](./linux) или [Docker Compose](./docker).
2. Войдите и опубликуйте первый файл. См. [Быстрый старт](../guide/quick-start).
3. Настройте [HTTPS](./https), прежде чем клиенты начнут подключаться с других компьютеров.
4. Подключите хранилище копий и выполните первую резервную копию. См. [Резервные копии](../operate/backups).
5. Выберите [политику обновлений](./updates).
