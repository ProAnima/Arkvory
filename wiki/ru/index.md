features:
  - title: Файлы любого размера
    details: Файлы размером в десятки гигабайт загружаются по частям, и загрузка продолжается после обрыва соединения. Скачивание возобновляется по диапазонам. Каждый файл проверяется по SHA-256.
    link: /ru/use/transfers
  - title: Пакеты и образы
    details: Пакеты UPack с версиями, образы контейнеров для Docker и Podman, Git LFS для игровых ресурсов, пакеты npm и Unity, а также обычные файлы по пути.
    link: /ru/protocols/
  - title: Понятный доступ
    details: Учётные записи, группы, персональные токены и сервисные учётные записи с ключами, ограниченными нужными репозиториями и действиями. Входы и изменения доступа фиксируются в журнале аудита.
    link: /ru/use/accounts
  - title: Стадии и продвижение
    details: Отметьте сборку как проверенную или выпущенную, продвиньте её в другой репозиторий, а агент развёртывания возьмёт самую новую сборку с нужной стадией.
    link: /ru/use/promotion
  - title: Резервные копии и зеркала
    details: Резервные копии по расписанию с проверкой — на локальный диск или в сетевую папку. Зеркала поддерживают второй сайт в актуальном состоянии и берут работу на себя, если первый утрачен.
    link: /ru/operate/backups
  - title: Работает сам
    details: Службы Windows, пакеты Linux или Docker Compose. Службы перезапускаются после сбоя или зависания, а обновления приходят подписанными и после свежей резервной копии.
    link: /ru/operate/self-healing
