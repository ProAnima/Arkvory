# Depot automation kit / Комплект автоматизации

For graphical Windows installation use Depot-Setup-x64.exe. On Linux use Depot-amd64.deb or Depot-x86_64.rpm with your package manager.

Для графической установки Windows используйте Depot-Setup-x64.exe. Для Linux — Depot-amd64.deb / Depot-x86_64.rpm через менеджер пакетов.

This archive contains the verified runtime and advanced install.ps1/install.sh entrypoint for external PostgreSQL or Compose. Node.js is downloaded with checksum validation; Docker must already be installed. See deploy/README.md in the repository. This archive is not a graphical installer.
