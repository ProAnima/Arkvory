# Arkvory automation kit / Комплект автоматизации

For graphical Windows installation use Arkvory-Setup-x64.exe. On Linux use Arkvory-amd64.deb or Arkvory-x86_64.rpm with your package manager.

Для графической установки Windows используйте Arkvory-Setup-x64.exe. Для Linux — Arkvory-amd64.deb / Arkvory-x86_64.rpm через менеджер пакетов.

This archive contains the verified runtime and advanced install.ps1/install.sh entrypoint for external PostgreSQL or Compose. Node.js is downloaded with checksum validation; Docker must already be installed. See deploy/README.md in the repository. This archive is not a graphical installer.
