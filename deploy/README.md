# Развёртывание

Runtime пока не реализован; этот каталог не содержит рабочего Docker Compose или production-манифестов.

Первый профиль: standalone для разработки/пилота с PostgreSQL и local blob volume. Он не гарантирует доступность при потере машины.

Промышленный HA-профиль появится после выбора инфраструктуры: несколько API/шлюзов, доступный входной адрес, HA PostgreSQL и проверенное отказоустойчивое blob storage. Нужны health/readiness, graceful shutdown, ограничения ресурсов, валидируемые секреты, резервирование и rollback.

Не копируйте параметры TLS, credentials или volume рабочего ProGet в примеры. Перед публикацией образа фиксируются версии runtime, непривилегированный пользователь, writable каталоги и политика обновлений.
