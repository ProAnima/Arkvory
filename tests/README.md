# Испытания

Место для будущих межпакетных контрактных, интеграционных, нагрузочных и отказных сценариев. Unit-тесты предметного кода размещаются рядом с ним.

Сейчас продуктовых тестов нет. `npm run check` проверяет только каркас и правила качества. Первый тестовый раннер и реальные сценарии добавляются вместе с первой передачей файла; тесты пустых модулей не нужны.

См. [стратегию проверок](../docs/TESTING.md). Большие файлы генерируются потоково, fixture-данные не содержат реальных секретов.
